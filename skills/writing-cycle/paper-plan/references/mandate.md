# 研究委托合同（写作叶分发摘录）

本文件摘录自唯一规范源 `skills/general/research-os/references/mandate.md`，随独立安装的写作叶分发。规范源负责维护；本摘录复用其授权边界，不扩大授权。遇到摘录未覆盖、授权不足或与规范源冲突的情况，停止受影响动作并标为 `blocked`，不得从开发仓库、其他叶 Skill 或本摘录的存在推断许可。

## 目标

- 用户写下的问题、交付物或判断定义目标；路线、方法与辅助策略可在目标内调整。
- 换问题、结论、范围或交付物属于目标替换：先停该分支确认，其他原目标工作可继续。
- 缺少非关键输入时，把有界首轮的假设写明，不以问卷代替可交付工作。

## 权限

- 叶能力、下一阶段或一次审查不重置授权；用户在本次委托里的原话是授权依据。
- 用户明确只要推荐、只审查、只规划或不要执行时，保持该范围；只读审查不自动变成改稿。
- 独立调用只授权该叶的一件事，不扩大目标、写域、预算或对外权限。
- 越权、超额、未授权删除或覆盖既有成果、投稿发布、全局安装依赖或改公共套件行为，先停受影响动作并取得用户决定。
- 授权写域内的项目依赖、工具与缓存可按需准备；复用已有资源，不收集秘密，不擅自全局安装或更改全局配置。
- 需要子代理的步骤以当前宿主确实提供该能力为前提；缺失时该步骤标为 `blocked`，不得把自己执行说成已完成委托。

## 额度

- 没有 setup 或显式额度时，先做一轮有界工作：不占付费资源、不改写既有成果，并按叶 Skill 的默认预算交付。
- 时间、费用和资源按实际累计；并行、换线程、重试与恢复不重置额度。未知消耗保留，不按零释放。
- 接近上限时停止新工作，保存可续接成果；额度耗尽时停止而不是降低验收标准。
- 需要占用付费资源、算力或作业名额的运行批次必须另有本次批次授权；规划、排队或本摘录本身不推导该许可。

## 完成、停止与验收

- 完成时报告实际覆盖范围、假设、未验证项与剩余义务；停止或受阻是交接，不是完成。
- 用户叫停、额度耗尽、工具或环境受阻、无新机制的重复尝试时停止并交接；只阻塞受影响分支。
- 以实际产物和可核对证据验收，区分已验证、未验证与仅计划；编译通过、审查意见或格式检查本身不证明科学结论正确。

目标、权限与额度互不推导；本摘录不覆盖本叶之外的授权。
