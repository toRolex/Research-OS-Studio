# 引用审计报告

## 范围与完成度

- 输入正文／bib 文件与范围；日期；standalone 或父报告职责。
- 实际扫描文件、唯一 cited key、全部引用位置数量；覆盖缺口。
- 可用来源与独立 fresh reviewer 实际完成情况、不可读取项。
- soft-only 是否开启；报告输出授权；研究材料未修改。
- 整体发现与完成度分开说明；没有正文引用／bib 缺失／部分未核实时写具体原因。

## 优先处理项

按错误语境、身份问题、元数据问题列出；每项附下方证据定位。已确认问题不能因另一轴未核实而被隐藏。

## 逐条证据

每个 cited key 都有一节，包括 KEEP 和缺失 bib 条目。

### key（bib 文件与定位）

- 原始条目与所指版本；建议 KEEP／FIX／REPLACE／REMOVE／UNVERIFIED（只是建议）。
- 身份：结论、查过的来源与查询、实际打开的 URL／原始文件、证据、版本分歧。
- 元数据：字段／当前值／来源值／正确、错误或未核实／依据；没有问题的字段也明确覆盖。

| 正文位置 | 原句与引用标记 | 对应 claim | 原始论文定位及证据 | SUPPORTS／WEAK／WRONG／UNVERIFIED | 理由与限制 |
|---|---|---|---|---|---|
| 每一处使用分别一行 | | | | | |

- 可选修复：涉及位置、当前／拟议内容、支持证据；replacement 已核实还是待查候选。
- reviewer 原始意见、实际阅读范围与分歧（篇幅大时只指向已授权的完整附件）。
- 未核实项与具体补证动作；引用身份、字段或某处语境的缺口分别列明。

## 无需改动条目

列出全部三轴通过的 key，逐条证据仍保留在上节；不把部分未核实项放入此列表。

## Uncited（仅显式开启时保留本节）

逐 bib 文件列出残余 key、prune／check 建议及具体本地意图证据。仅建议，不核实、不删除、不改变总体结论。枚举失败写无法计算及原因，而非零条。

## Soft-only 改写（仅冻结开启时保留本节）

所有 bib 冻结；按问题发生位置列原句、拟议句、理由、原始支持证据、仍未解决的元数据／身份问题。明确正文引用移除或改用现有 bib 来源的特例，以及额外冻结引用标记导致的不可执行项。

## 待用户决定与停止

哪些已确认、哪些未核实；哪些修复可考虑，哪些需要补证。没有任何研究材料变更。用户可另行显式调用 apply-citation-fixes；此报告不自动应用、不决定投稿就绪。
