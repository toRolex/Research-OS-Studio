# Academic Plotting

将 ARIS `paper-figure` 的图表交付方法与 Orchestra `academic-plotting` 的数据图、示意图方法组合。产物是用户项目中的自然格式图、源文件和可读说明，不依赖 Research OS runtime。

## 角色与授权

默认 **model-invoked**：只在当前已授权的图表职责内调用；用户也能点名 **standalone**。**composed** 接收父任务指定的图号、原始材料、写入范围、资源预算与主报告位置，只返回／贡献图表部分。父任务的消息不是额外用户授权。

- 输入：真实数据及其来源／单位／实验条件，或方法说明及组件关系；可选图表计划、现有图片、用户模板及目标尺寸。没有计划时，只探索用户指定材料位置，提出候选图表并确认选择；不要求先运行 setup、实验或论文规划。
- 写入：仅批准的图表目录（含源脚本、局部样式文件、可编辑图源、导出图、表格、caption、可选 LaTeX 引用片段）及指定报告区块。原始数据、现有手工作图、论文正文和环境配置保持不动。同名产物冲突先询问或使用已批准的新路径。
- 资源：默认本地、已有环境、一次生成及至多一次局部修正。先确定时间／图数上限；父授权更窄时从窄。外部数据读取须在授权来源内；远程上传、模型图像生成、付费及独立 reviewer 的外部调用须有明确内容／预算授权，否则停止对应分支。
- 完成后停止，不启动写作、实验、编译整篇论文或其他顶层 Workflow；不会安装依赖、配置凭据、下载字体或修复用户工具链。

## 1. 盘点并选图

读完整相关数据、方法上下文和已有图，不只读上游任务摘要。按 [figure-note.md](templates/figure-note.md) 的字段记录每个图号、目的、来源、类型、输出路径及授权范围；简单单图可直接用报告中的一个小节，无需制造空文件。

| 内容 | 本能力处理方式 |
|---|---|
| 数据图／比较表 | 每个数值可追溯到给定原始文件、字段／行与变换；不可由图像生成器绘制定量证据 |
| 架构／流程／概念示意图 | 从方法提取组件、边、方向和精确标签；标注“示意图／Schematic — not experimental evidence” |
| 真实照片、截图、模型生成样本网格 | 只使用已有且允许使用的素材，保留出处；没有素材时列为缺口，不补造 |
| 混合图 | 逐 panel 区分证据和示意；图注解释各自来源，不让示意部分承担结果证明 |

有数轴不一定是实测图：理论曲线须提供公式、参数、假设并标作理论／模拟；玩具数据只能在用户明确要求时作为标注的演示，不能填充缺失科研结果。

**完成条件**：每张图已分类，所需来源可读取，已有图保护范围、图数及写入位置明确；缺失或含混的来源／单位／关系列出具体问题，暂停该图。

## 2. 检查现有能力

先读项目环境约定，定位用户已有解释器／绘图工具并做最小导入或版本探测。只检查当前选定分支所需能力：Matplotlib 数据图不强制 Seaborn、SciPy、LaTeX 或远程模型；简单示意图可用 SVG 文本源或已有 DOT／TikZ／Mermaid 工具。

Python 操作使用已有 uv 和明确的现有解释器。例如替换为实际绝对路径后执行 `uv run --no-project --offline --no-python-downloads --python /existing/venv/bin/python -- python -c 'import matplotlib; print(matplotlib.__version__)'`。这是能力探测，不是安装命令；先确认路径存在。运行图脚本也用该环境，不加依赖声明、`--with` 或同步操作；选择不带安装副作用的项目已有运行方式也可。缓存／中间渲染文件安排在批准的临时或输出目录。

缺库、工具、字体或渲染读取能力：报告实际探测命令、错误及受影响产物，停止该分支。可提出使用现有替代工具或仅交付可编辑未渲染草稿，获准后执行；未运行、未渲染和未目检分别标明。远程生成可用也不等于已获上传权限。

**完成条件**：选定工具实际可用且副作用在授权内，或该图有明确阻塞说明；不以环境补装作为后续步骤。

## 3. 按类型制作

### 数据图／表：来源先于造型

读取 [data-visualization.md](references/data-visualization.md) 的选定模式及 [style-guide.md](references/style-guide.md) 的最终尺寸／图注规则。数据维度决定图形：时间／步数用线图，分类比较用分组柱图或点图，双连续变量用散点图，矩阵用热图，分布用箱线／小提琴，多数据集用多面板，组成比例用堆叠柱图。不能因“本方法”需要突出而改变比较尺度。

1. 确认字段、单位、样本／重复试验单位、全部比较条件及缺失／排除标记。记录筛选、聚合、归一化、排序、拟合、平滑和轴变换；未授权分析不在制图中偷偷完成。
2. 每个 plotted mark／表格单元格映射到源文件行／组及变换。排除行不进入汇总；若展示它们，另用明确图例。不同预算／样本数／协议分 panel 或明确标示差异。原始数据不覆盖，必要的派生表与变换代码并存。
3. 汇总须给 n 和重复单位。SD、SE、CI 分别命名，注明计算方法；没有重复观测不编造误差带。筛选赢家、删失败运行、改变分母均须显式披露；超出已有证据的统计推断作为待用户决定的分析需求。
4. 每图保留独立可重跑脚本，直接读源文件而非复制手填数列；共用样式只放本次图表目录。源日志中的数字先抽取到带行号说明的自然格式数据文件并核对。资源中的代码块是适配模式，不是完整实验或可直接批跑的脚本。
5. 比较表用 Markdown 或用户需要的独立 `.tex`，依 [table-and-review.md](references/table-and-review.md) 保留符号定义、来源与未验证项。数据图默认矢量 PDF／SVG 及可用的 PNG 预览；具体格式由授权需求和已有导出能力决定。

**完成条件**：每张图／表的数据映射和变换可查，源文件可编辑且运行命令完整；无资料的单元格明确为空缺，不生成“占位结果”。

### 示意图：语义先于风格

读 [diagram-generation.md](references/diagram-generation.md) 的完整六段设计方法；选风格时再读 [diagram-styles.md](references/diagram-styles.md)。

1. 从上下文提取实体、关系、数据／控制／条件路径和逐字标签。超过八个顶层实体先分组；流水线左至右、分层横带、中心辐射、层次树按语义选择。无法确认的箭头提出问题或标为 proposed，不依据美观补边。
2. 保存六段可编辑设计说明：framing、visual style、palette、layout、connections、constraints。每条边逐一写出起点、终点、方向、路由、标签与条件；示例中的模型规模／指标不是用户事实。
3. 优先交付 SVG、DOT、TikZ、Mermaid 等可编辑图源及实际可用的渲染图。需要 AI 渲染时先完成资源授权，保存提示词、工具／模型标识、设置、全部尝试及选择理由，同时保留可编辑的结构图源；提示词和 PNG 本身不构成像素级复现保证。
4. 图内及 caption 明确标注示意图，不是实验结果。已有图片只引用和说明，未经授权不覆盖。缺渲染器可交付已授权的未渲染源，但状态保持“未渲染”。

**完成条件**：每个实体／箭头能回指说明，示意身份可见，存在可编辑结构源，生成与未生成的部分明确区分。

## 4. 实际运行并复核

逐个审核后运行本次批准的脚本／导出命令，不对目录内所有脚本通配执行。记录工作目录、解释器与依赖版本、输入位置、命令、退出状态和输出。生成失败保留错误；不把旧图的存在当成本次成功。

然后读取**实际导出的图**，按最终打印尺寸检查轴／单位／图例、截断、重叠、字体、灰度可辨性、箭头方向和全部标签。SVG／PDF 包装不自动意味着内容矢量或文字可编辑。不能读图时只报告执行与静态结果，视觉检查待完成。

使用 [table-and-review.md](references/table-and-review.md) 的质量提示，逐项将 caption 与全部 plotted rows／方法说明核对。任何反例须收窄结论或改为描述；审查发现不能通过篡改数据修复。可在授权预算内做一次局部图形修正，重新导出并复核，仍失败则列明待解决项。独立 reviewer 可用且获授权时读取原始数据与渲染图，而非只收到 caption；否则明确“仅自查”，不伪称独立审查。

**完成条件**：每图都有“数据对应／运行／渲染目检／自查或独立意见”的实际状态及缺口；模型意见不等于科研真理或用户验收。

## 5. 交付并停止

standalone 在批准目录保存填写后的图表说明；composed 将相同信息贡献到授权主报告区块，避免双份权威报告。交付图／表、源脚本或结构源、数据位置及映射、复现命令、caption、可选 LaTeX 引用片段、失败与未检查项。引用片段仅是片段，不能声称整篇论文编译成功。

明确停在图表候选完成／部分完成／阻塞；下一步仅提出建议，由用户决定是否采用、改图或启动其他流程。许可证见随包 [ARIS MIT](LICENSE-ARIS.txt)、[Orchestra MIT](LICENSE-Orchestra.txt)。
