# 视觉精修：只读审查与授权后的布局修复

用于内容已锁定的学术报告：对现有 Beamer、PPTX 及其实际渲染逐页检查视觉重量、字体、边界和样式漂移。本文件提供方法，不提供额外公开入口。论点、引用、匿名与报告等级的完整审计见同目录 [talk-audit.md](talk-audit.md)。

## 1. 范围、授权与停止条件

- **审计只读**：审查者只观察、定位、提出建议；发现问题不等于获得修改授权。执行者仅在用户已授权视觉修复时，在新版本副本应用布局修复；授权可覆盖一个明确的小批次，不必对已授权的每个位置重复询问。
- **内容锁定**：正文、标题措辞、数字、论点、结果、引用、链接、作者、单位、匿名占位符、图像及公式含义均保持不变。不得改写、删减、补全或从参考报告借用文字、例子、标题、notes。任何建议涉及内容或 notes 变化，停止该修复并另问用户；不得以“只是排版”为由执行。
- **原版不变**：原始论文、原始幻灯片及关联资源只读。获授权后创建不覆盖现有文件的新版本副本，例如 `<stem>_polished`、`<stem>_polished_v2`；Beamer 依赖文件的修改也限于副本。保留原版及本次各轮副本，不自动清理。
- **notes 原样保留**：保持原有 notes 的存在性、逐字内容、结构和相关关系；没有 notes 的页仍保持没有。检查不得因访问接口而意外创建 notes。伴随的讲稿与 notes 文档不修改。保存后直接比较原版与输出中的 notes 内容及相关部分；工具重写导致不能确认原样保留时，标明未验证并停止通过判定。
- **页序不变**：新增、删除、重排或拆分逻辑页须另获明确授权。Beamer overlays 的多张物理页不是新增逻辑页，见第 2 节映射规则。
- **匿名失败即停止**：不推断或填入真实论文标题、作者、投稿数量、链接。既有通用占位符原样保留；发现既有泄露也只报告，替换文字另行授权。
- **小预算、有界复核**：当前授权内默认最多 **2 轮“审查—授权修复—重渲染—复核”**。开始前说明本次处理页、可用时间/调用额度及先到即停的预算；未另定额度时每轮最多深审 3 个问题逻辑页，先 BLOCKER 再 NEEDS-WORK。全页初筛不能用抽样冒充；容量不足则分批只读检查，预算到即报告未覆盖页。PASS 页不改。不因剩余小瑕疵自动扩大批次、追逐完美或追加轮次。
- **真实能力**：只用宿主已有的解析、编辑、编译、渲染和独立视觉审查能力，不固定提供商、模型或运行服务，不自动安装依赖。缺能力时请求用户提供实际导出/渲染或独立审查结果。文本抽取不是视觉渲染；自审不是独立审查；未渲染、未独立审查不得标记视觉 PASS 或宣称精修验收通过。

完成条件：明确输入、参考、只读/可修复授权、预算及不能越过的内容边界。

## 2. 输入与逻辑页映射

1. 列明现有源文件、实际二进制文件、基线、声明画幅、notes 与讲稿、用户选择的参考。只有源码时先如实说明尚无可看的成品。
2. 视觉参考优先采用用户指定的 PDF；同一报告的 Beamer 实际编译 PDF 可以作为 PPTX 自参考，但须明确采用理由并获用户认可。没有参考则询问，不悄悄套用示例预设。参考仅是视觉锚点，不是学术事实或文字来源。
3. 记录参考属于“同报告逐页对应”还是“外部风格参考”。外部参考无需页数相同：为待审逻辑页指定适当参考页或元素，解释比较的是标题层级、字重、配色、留白还是卡片密度，不伪装内容一一对应。
4. 建立自然 Markdown 映射表：逻辑页标识/标题、源 frame 或 PPTX 页位置、Beamer PDF 物理页范围、PPTX PDF 物理页范围、参考页、overlay/动画说明。逻辑身份以原始页序和源位置为基础，标题只能辅助，重名不能充当唯一键。
5. Beamer 一帧可能因逐步揭示生成多个 PDF 页；每个 overlay 都要检查可见元素、揭示顺序和越界。PPTX 导出可能只保留动画终态；注明未验证的动画行为。两种格式不强求物理页数相等，核对逻辑页覆盖、顺序和对应内容；无法解释的缺页、重复或映射歧义才是阻断。
6. 取得待审版本和参考的真实逐页渲染，常用约 150 dpi 起步，小字/公式不清时局部放大。PPTX 必须来自该版本实际导出的 PDF 或等效真实页面图；Beamer 必须来自该版本实际编译结果。

完成条件：每个逻辑页及全部物理渲染有可追溯的对应关系；缺失、动画限制和无参考项显式列出，不能算通过。

## 3. 元素定位：按源格式建立自然 Markdown 清单

在原版上只读提取清单，修改前对副本目标重新定位。先按格式选分支，不为 Beamer 虚构 PPTX 的 shape 属性。

### Beamer：源位置与渲染区域

逐个逻辑 frame 记录源文件绝对路径、frame 标识/标题、源码行范围、唯一原文片段、overlay 条件及对应 PDF 物理页。共享宏/主题样式列定义位置和所有受影响 frame。用真实渲染中的区域、相邻文字/图、标题层级定位视觉问题；可测时记录渲染边界，无法可靠取得几何量则标为未知，只阻断依赖该量的修改。

修改前确认源片段唯一，重复片段结合 frame 与上下文消歧；零个或多个目标则停下询问。以源码中的长度/字号/容器约束给前后差异，不假设 PDF 内存在可编辑文本框、placeholder、组路径或稳定 shape ID。只提供 PDF 而没有可编辑源时可审查渲染，源修改请求未满足，不能反编译猜测结构。

完成条件：每个待审 frame/overlay 有可追溯的源定位与实际渲染；每项拟修改有唯一源目标，未知几何不被当作确定值。

### PPTX：Shape inventory

无需统一机器格式；按“逻辑页 → 对象路径 → 属性”列 Markdown。以下对象属性与定位规则仅用于 PPTX。

每份清单包括总逻辑页数、物理页映射、画幅尺寸；每页包含页码文字、标题、notes 存在性及原样比对基线。每个对象记录：

- 对象 ID、名称、种类：文本框、图片、自选形状、组、表格、连接线、占位符。
- 从最外层组到叶子的完整对象 ID 路径、父组路径；递归列出组内所有对象，不只看页根。
- 占位符类别，如标题、正文、对象；表格逐格记录行、列、合并关系和所处表格路径。
- 完整原文，逐段/逐 run 的原文、字号、粗体、斜体、颜色；继承或未知值如实标记，检查主题/母版/段落继承后才确认有效样式。
- 边界框 left/top/width/height、旋转、内边距、行距和段距；单位统一为英寸，必要时保留到小数点后 4 位。原生几何单位转换时，1 英寸为 914400 EMU。
- 组内局部坐标与换算后的页面坐标，包含嵌套组缩放/旋转影响；无法可靠换算则阻断移动操作。
- 填充与描边颜色（包含主题色或透明情况）；图片原始像素宽高、裁剪及显示宽高比；连接线端点/箭头方向。

示例条目：

> 逻辑页 3，PPTX 第 3 页，标题“……”。notes：原有，基线已读取。
>
> 对象路径：组 8 / 组 12 / 文本框 19；名称：结论框；原文：“……”；字号：24 pt，粗体；页面框：L 0.50、T 5.80、W 11.90、H 0.70 in；填充：浅强调色；描边：无。
>
> 表格路径：组 8 / 表格 22；单元格：第 2 行第 3 列；原文：“……”；继承字号尚未确定。

### 唯一定位与歧义停止

1. 在指定逻辑页内，用原文的足够长唯一前缀/子串匹配，递归搜索组、文本占位符、表格单元格。
2. 文本只匹配对应叶子，不同时将组汇总文字算作第二个目标。必要时结合种类、完整组路径、表格行列、占位符类别、边界框消歧。
3. 图片或无文字对象用清单中的完整路径、种类和几何特征定位；不要捏造文本匹配。
4. 零个或多个候选都停止，不选“第一个”，不只依赖会漂移的对象数组索引。让用户明确对象，或补充足以得到唯一候选的证据再继续。
5. 应用前再次确认原文、路径和旧几何与清单一致；不一致先刷新定位。合并单元格、继承占位符、嵌套变换不能安全编辑时，输出诊断而非破坏性降级。

完成条件：所有对象均有可读清单，拟修复对象能唯一定位；未知样式和几何不会被当成确定事实。

## 4. 全页 triage：完整提示

交给宿主已有的独立视觉审查者；使用独立的新上下文，只读访问当前渲染和必要参考，不给作者的自评分或旧修复清单。一次全套或预算内分批覆盖全部页面，不能仅看缩略图后猜测小字。

```text
你是只读视觉审查者。对 <当前版本及其真实渲染> 的全部 N 个逻辑页
进行 triage，对照 <参考真实渲染> 与 <逻辑页/物理页/参考映射>。
映射中的每个 overlay 都在范围内。外部风格参考只比较指定视觉元素，
不要求内容或物理页数一致。不要修改任何文件。

每个逻辑页输出一行，必要时注明 overlay/物理页：
逻辑页 K | PASS / NEEDS-WORK / BLOCKER — 一句话理由

逐项关注：
- 与参考的视觉重量、层级、留白及文字投影可读性；
- 文本框溢出、被裁切、对象相撞及页码重叠；
- 标题尴尬换行、长名词拆行、正文行尾孤词；
- 斜体样式泄漏、非预期继承、中文方框或缺字；
- callout/横幅的真实填充、色彩纪律和密度；
- 匿名占位位置是否出现真实标题、身份、数量或链接；
- overlay 揭示是否缺内容、产生意外空白或遮挡。

不得改写内容，不给已经清楚可读的页建议一刀切放大字号；
不评价或改写 speaker notes。发现匿名泄露只报告，不提出猜测补全。
缺少真实渲染、参考映射或独立观察的页标为“未验证/阻断”，
不能用 PASS 填空，也不能将文本抽取当作已看过页面。

最后一行：B 个 BLOCKER，W 个 NEEDS-WORK，P 个 PASS，U 个未验证；
列出未覆盖页和依赖限制，数量须覆盖全部 N 个逻辑页。
```

先向用户呈现逐页矩阵，再进入获授权的深审或修改；优先影响阅读、缺字、越界和匿名问题。匿名/内容问题进入单独授权边界，不能作为视觉修复自动处理。

完成条件：每页有结论或明确未验证原因；问题页及本批次预算已确定。

## 5. 逐页 fresh review：完整提示

对当前批次的 NEEDS-WORK/BLOCKER 页逐页进行，不以一次批量泛评替代。每页使用独立新上下文；不携带上一轮结论或“已经修好了”的暗示。fresh 指审查独立性，不绑定特定模型；无法取得独立审查时可做自检，但不得称独立审查已完成。

```text
只读审查逻辑页 K，不修改文件。

输入：
- 当前 PPTX/Beamer 该逻辑页的实际渲染：<页面图及所有 overlay 图>
- 参考页面渲染：<对应图>
- 映射与比较范围：<同报告对应关系，或外部参考的视觉元素>
- 当前源文件：<版本路径与 frame/逻辑页位置>
- 本页定位清单：<PPTX 的完整对象路径/属性；或 Beamer 的源文件、
  frame/行范围、overlay、唯一源片段与渲染区域；未知几何明确标记>
- 本页标题原文：“<标题>”
- 风格锚点：<generic 或 why-rf（如适用）> + <参考 PDF>

给出：
1. 状态：PASS / NEEDS-WORK / BROKEN；资料不足则“未验证/阻断”。
2. 做得好的地方：1–2 项具体观察。
3. 相对参考的漂移：1–3 项，指出物理页/overlay 及具体对象。
4. 可执行的布局修复建议：字号、位置、框尺寸、颜色、斜体作用域、
   行距/段距等的修改前后值或源片段；按“先 font，后 frame”排序。
   文本对象按足够长且唯一的原文前缀/子串定位，结合组路径、类型、
   单元格位置或边界框；不得仅凭数组索引。匹配有歧义立即停止，
   请求人工消歧，不触碰第一个候选。无文本对象使用完整路径与几何证据。
   Beamer 则按源文件/frame/行范围与唯一源片段定位，给源码前后差异；
   不索取或编造 PPTX shape ID，无法可靠测量的几何量标未知。
5. 若修复涉及 claims、数字、引用、匿名占位符、正文措辞、图/公式内容、
   notes 或页序变化，STOP，指出越界项，不提供可直接套用的内容改写。

遵守参考只供视觉指导；不复制参考的文字。审查者只有只读权限，
建议不代表执行授权。只评价所见，不把未渲染或未独立验证说成通过。
结尾：VERDICT: PASS / NEEDS-WORK / BROKEN / 未验证。
正文控制在约 500 词或相当长度以内，保留定位与修改前后值。
```

BROKEN 作为全页矩阵的 BLOCKER。执行者检查授权和内容边界后，才在新版本副本逐项应用建议；建议本身不是可盲目执行的补丁。安全保存后保留上一可读版本，重新编译/导出并渲染本页及受共享样式影响的页。每条变更用自然 Markdown 记“逻辑页/对象、前后值、原因、复核结论”，不要求另建管理文件。

完成条件：每个已改对象有唯一定位、授权内的前后差异和真实重渲染；否则仍未验证。

## 6. 字号策略：先 font，再 frame

16:9、约 13.33 × 7.5 英寸 PPTX 与 Beamer 对齐视觉重量时，1.6 倍仅是经验起点，常见范围 1.5–1.8 倍；下表按角色校准，并非机械倍乘规则。已可读页面不缩放。画幅、字体字面大小、参考与投影效果优先。

| Beamer 字号 | PPTX 目标字号 | 角色 |
|---|---|---|
| 8 / 8.5 pt | 14–18 pt，小型大写 | section label |
| 10 pt 斜体 | 14 pt 斜体 | 灰色提示/线索 |
| 11 pt 正文 | 22–24 pt | 项目符号、段落 |
| 12 pt 页码 | 16 pt，上限 16 | 右下灰色 N / total |
| 14 pt 强调正文 | 22–24 pt | 较大子标题 |
| 16 pt callout | 24–28 pt | eqbox / yellowstrip 正文 |
| 17–22 pt 大数字 | 28–36 pt | 核心统计、漏斗数字 |
| 22 pt frame 标题 | 40–44 pt | 普通页标题 |
| 28 pt hero 强调 | 36–44 pt | 核心大字 |
| 42 pt 封面字标 | 80–100 pt，纯黑 | why-rf 示例封面纪律 |

本方法 PPTX 页码保持不超过 16 pt，不跟正文一起倍增。这是视觉建议，不是会议官方规则。

完成字号调整后再修复边界框、邻接元素和栏宽：

1. **标题压到副标题/正文**：例如 100 pt 标题仍装在 0.95 英寸高框内，字形可能约 1.4 英寸高。增加框高，同时下移下一元素，不能只改字号或只移动文字。
2. **正文长词组断成孤词**：旧框宽不足以容纳新字号，扩大正文框并相应缩窄邻栏，检查两栏最小可读宽度；无法容纳时报告，不擅自删字。
3. 重查换行、顶部/底部内边距、行距、图注和页码；用清单的边界框提供具体前后值。
4. 重新执行全页 triage，防止全局字体/母版变化使原先 PASS 页退化；深审仍服从两轮与小预算上限。

## 7. Beamer 修复 catalog：完整七项

仅在已有源文件及宿主编译能力可用时采用。每项先确认现有模板、包与字体能力；缺失则报告，不自动补装。源片段中的颜色、尺寸和字体是示意，实际以授权参考为准。

1. **Frame 标题字号与细下划线**。在 `beamercolorbox` 标题模板内部，标题文字之后放 `\hrule height 0.55pt`；不是在盒外孤立放 `\rule{...}{...}`，后者可能落到右上而非标题下。调标题字号时同时检查基线、内边距、下方正文起点和所有 overlays。
2. **小型大写强调色 mini-header：`\sectionlabel`**。使用无衬线、小字号、加字距与大写，保持段内作用域：

   ```latex
   % accent 为当前模板已有的强调色；textls 需要已有 microtype 支持。
   \newcommand{\sectionlabel}[1]{%
     {\sffamily\fontsize{8}{10}\selectfont
      \textcolor{accent}{\textls[200]{\MakeUppercase{#1}}}}}
   ```

   缺少字距支持时先报告兼容性，不静默改变整套模板。
3. **卡片窄列左对齐**。已有 `array` 支持时，用 `>{\raggedright\arraybackslash}p{Xcm}`，其中 X 是实际列宽；避免窄表格单元格两端对齐产生空白河流和词中断行。检查列宽总和及列间距，不改内容。
4. **Banner 必须是真实色块**。在已有能力支持时用真实 `tcolorbox` 容器，设置填充、边框和内边距；`\begin{center}\color{...}` 只会产生居中的有色文字，不会得到横幅。新增背景形状不得遮住原内容。
5. **Em-dash 间距**。优先在源中用 `\textemdash{}` 明确命令边界，或用 `\,---\,` 表达细空格；裸 `—` 的相邻空白可能被压缩。保持原文字与标点语义不变；若修改改变文本抽取结果而非仅显示间距，转入内容边界另问。
6. **`\sectionlabel` 内颜色泄漏/编译错误**。把 `\textcolor{red}{...}` 放在 `\MakeUppercase` 的参数内可能将颜色名称也变为大写，导致颜色未定义。将颜色作用放在大写转换之外，或采用已有的独立带色变体（例如项目已有的 `\sectionlabel*`），不要把未定义星号命令直接塞进源。局部修复后检查其他 section labels。
7. **CJK 与数学混排**。使用当前项目已支持的 Unicode/CJK 编译方式和已有中文支持（如 `ctex` 或 `xeCJK`），明确选择宿主可用且覆盖所需字形的字体，不强制特定本机字体或固定 fontset。中文英文混合标题要确认中文字符没有落入仅含拉丁字形的字体；同时检查公式符号、粗体与标点回退。只读检查警告并查看实际页面，编译成功不能代替缺字检查。

完成条件：适用的七项逐项检查；修改后真实编译成功，全部受影响 frame/overlay 已重渲染，内容不变。

## 8. PPTX pitfalls：完整八项

1. **图片宽高比**：只改 width 会拉伸图片。无裁剪原图按 `新高度 = 新宽度 × 原图像素高 / 原图像素宽` 等比调整；有裁剪时保留裁剪关系和可见范围，不能用原图公式覆盖既有裁剪设计。不得改变数据图内容或遮掉坐标轴。
2. **Banner 是有填充的矩形**：用位于文字之后的独立填充矩形等效真实色块，而不是只给字染色。检查层叠关系、边框、内边距和透明度，不能盖住正文或链接对象。
3. **曲线箭头能力差异**：常见 PPTX 编辑能力没有现成曲线箭头。若宿主支持可使用真实曲线路径；不支持时，可在授权允许且含义不变的前提下，用垂直加水平两段直线连接器近似，或用确实支持曲线控制点的自由路径。普通折线自由形状不等于 Bezier。记录近似、端点、箭头方向；无法保留反馈/因果语义则停止，不靠换图掩盖。
4. **斜体样式泄漏**：源中未限定作用域的 `\itshape` 可能让同段后续 runs 全变斜体；限定为 `{\itshape ...}` 或仅作用于目标 run。PPTX 中检查 run、段落、占位符、母版的继承，保留真正用于变量和提示的斜体，不全局清空。
5. **中文渲染**：除了拉丁字体还需检查 East Asian 字体提示及回退，例如 `<a:ea typeface="实际可用的中文字体"/>` 中应填写已验证可用的字形覆盖字体，而非照抄占位文字。不能强制指定某个操作系统专属字体。实际导出检查中文、数学符号和粗体是否变成方框；声明了字体不等于已嵌入，也不等于目标机器可用。
6. **Em-dash 间距**：裸 `—` 可能显示空白塌缩，优先调整字距等纯样式。可提出带两侧空格的 `" — "` 或等宽空格方案，但这会改变文字序列，须停止并另获内容修改授权；不能在内容锁定的批次悄悄替换。
7. **循环箭头/反馈标签越界**：检查标签整个边界框及连接线，左/上约 0.4 英寸安全边距可作参考，并检查右/下是否在画幅内。PPTX 会静默裁切画外内容，靠左上弯曲标签尤其易出错。组内坐标必须先换成页面坐标，不能只检测 left/top 为正。
8. **匿名占位符纪律**：保留诸如 `Withheld for anonymous review`、`[anonymized]` 的既有通用表述，不推断真实标题、统计、作者或链接。扫描可见页、notes、讲稿以及已有隐藏对象/链接/文档属性中可能带出的身份信息；发现问题只报告，跨入内容修改前另问。参考中的身份信息也不能带入。

完成条件：八项全部判定为已检查、确实不适用或未验证；缺字、语义改变、匿名泄露不能算小瑕疵放行。

## 9. 参考样式与元素方法

以下是**非官方视觉经验预设**，不是任何会议/投稿的正式要求，也不替代用户明确选定的真实参考。会议名称本身不能推导官方字体、色板或模板。外部参考只供视觉重量和结构节奏；不能用它导入事实或文字。

### generic

- 黑色文字 + 一个强调色，例如 `#2563EB`。
- 仅在承载信息层级确有必要时使用一种中性背景；不要给每条内容都加彩色卡片。
- 用字重、对齐、留白和字号建立层级，再用颜色标示重点；无需为了套预设给原本清楚的页面加框。

### why-rf：学术极简示例

源自一类 rectified-flow 学术报告的视觉纪律；是可选例子，不自动作为无参考时的替代品。下表与第 6 节的角色字号表用途不同：这里描述该示例的整套元素比例，最终以实际参考渲染为准。

| 元素 | Beamer 示例 | PPTX 示例 | 方法 |
|---|---|---|---|
| Frame 标题 | `\fontsize{22}{26}` | 40–44 pt 无衬线粗体 | 下方全宽 0.55 pt 强调色细线 |
| 正文 | 11 pt | 22–26 pt | 使用已有、可投影阅读的无衬线等效字体 |
| 卡片标题 chorebox | 11 pt 粗体 | 20–26 pt 粗体 | 放在卡片内部，层级低于页标题 |
| Section label | 8 pt 小型大写 | 16–18 pt 小型大写、宽字距 | 主强调色，局部作用域 |
| 灰色斜体提示 | `\scriptsize\itshape` | 12–14 pt 斜体 | 页灰色，不让斜体泄漏 |
| 页码 | `\footnotesize` | 14–16 pt | 右下灰色，保持次要 |
| 封面标题 | 44 pt 纯黑 | 80–100 pt 纯黑 | 不是强调色字标；检查大字框高 |

色板只在有信息职责时少量使用：

- 主强调色：例如 `#2E75B6`，用于标题线、section label。
- 深强调色：例如 `#1F4E79`，用于 chip 背景、重点大数字。
- 浅 callout 背景：例如 `#DEEBF7`，用于必要假设或结论。
- 诚实披露黄：例如 `#FFF4CC`，用于限制与披露。
- 审查问题红：例如 `#C00000`，仅用于安全免责声明，不拿红色营销。
- 页灰：例如 `#808080`，用于页码和次要提示。
- 深色正文：例如 `#1F1F1F`，维持主阅读对比。

完整元素库：

- **chorebox**：白底、顶部细强调色线、section label、粗体卡片标题、正文；检查五层组合的间距，不堆双重边框。
- **eqbox**：浅强调色全宽横幅，仅承载关键假设/结论；保留公式含义与上下文。
- **yellowstrip**：诚实披露黄底、左侧 3 pt 橙线，仅用于真实限制/披露；不创造新的免责声明文字。
- **redbox**：浅红底、红边框，仅用于已有的安全免责声明。
- **banner**：浅强调色全宽条与简短既有说明文字，用真实填充容器，不是居中文字染色。

整体纪律：彩色框少于常见装饰性模板。纯装饰卡片可在获授权且文字、顺序、层级不变时改为朴素项目符号视觉；移除营销装饰只限图形样式，不能删除正文。无需把每一种元素都用一次。

## 10. 有界复核与最终导出完整性

### 10.1 每轮复核

1. 从实际新版本重新保存/编译、导出、逐页渲染；不能复用旧页面图证明新文件正确。
2. 使用第 4 节提示重新全页 triage，共享模板或字体影响的页也覆盖；问题页按第 5 节独立 fresh review，预算不足明确未覆盖。
3. 比较原版与新版本的文字、数字、引用、链接、作者、单位、图/公式内容、逻辑页序、notes 存在性及原样内容。直接比对，不以肉眼“看起来没变”代替内容与 notes 检查。
4. 再查匿名占位与新增身份泄露；视觉修复提议若越界立即停止，交由用户决定，不自行修复审计结论。
5. 到两轮上限或小预算上限即停止，列明已改、未改、未验证和下一步需用户授权的事项。不要以“还有两处”自动续跑。

零 BLOCKER、最多两页轻微 NEEDS-WORK 可作为停止继续投入的经验信号，**不是无条件 PASS**：剩余问题逐项标警告，全部视觉检查确实通过才给视觉 PASS。未独立复核、未渲染、内容/notes 未确认稳定均不得通过。

### 10.2 导出检查清单

- **真实文件**：确定本次最终选择的是哪个实际版本，文件存在、非空、可解析并可打开。只有 Markdown、源文件、建议代码或预期路径时，明确“尚未生成 PPTX/PDF 二进制”，不得说导出成功。
- **版本一致**：Beamer 从授权副本及其实际依赖编译；PPTX PDF 从最终选定 PPTX 导出。检查编译/转换错误和警告、缺失资源及陈旧输出，不拿原版 PDF 冒充新版本。
- **逻辑覆盖**：按第 2 节映射核对大纲/基线逻辑页、源页、Beamer overlays 与 PPTX 导出页。允许有解释的物理页数差异；缺逻辑页、未解释重复、错序、遗漏 overlay、意外空白须报告。预期动画中间空白也需有源依据，不盲目当成损坏。
- **画幅与边界**：每种实际导出符合声明画幅，而不是一律假设 16:9；无意外全空白页，无裁切、标题重叠、页码遮挡、画外标签和缺字。
- **字体与可读性**：验证实际显示字形、中文与数学混排、替换/嵌入情况及投影可读性；字体名称不等于嵌入证明。不能在本机验证的跨机器回退明确列为限制。
- **媒体与对象**：图像不变形、裁剪不丢关键信息；公式、表格、箭头和链接含义完整；不支持的动画、曲线或嵌入媒体逐项标记未验证，不以静态截图证明动态行为。
- **内容和 notes**：原版与输出的内容及 notes 按第 1 节边界保持不变，notes 附属关系和原先无 notes 的页也检查。纯视觉授权下有任何内容差异即阻断。
- **匿名**：最终实际成品的可见内容与可检查的附属内容不存在新增身份泄露；任何泄露或无法完成必要匿名检查都不授予匿名验收通过。

### 10.3 输出结论

用简短自然 Markdown 报告：实际成品路径与格式、原版保留情况、逻辑页/物理页及 overlay 映射、完成轮数、逐页结论、布局变更前后值、内容与 notes 比对、独立审查覆盖、导出检查、剩余警告和阻断。路径只报告真实存在的文件；不存在的产物写为缺失，不能伪造链接式交付。

视觉 PASS 只说明所述版本的已完成视觉范围，不证明论点和引用可靠，也不授予 conference-ready 认证。最终报告还须包含 [talk-audit.md](talk-audit.md) 的只读审查与本节导出结果；任何必需项未运行、未验证或未通过都须准确列出。审计建议仍由执行者另获授权后处理。
