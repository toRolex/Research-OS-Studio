# PDF 与投稿核验

逐项记录“通过 / 不通过 / 未检查 / 不适用”及证据。存在可疑输出时可以诊断；只有本次构建退出码为零且新 PDF 实际解析成功，才可称“构建成功且 PDF 可读”。投稿就绪还要求适用检查全部通过。

## 1. 存在、新鲜性与实际解析

确认 PDF 位于本次新 output、是非链接普通文件、大小非零，路径与实际入口 jobname 相符。把本次运行编号、退出状态、产物生成证据关联起来；旧 PDF 即使时间新、名字一致也不是本次成功。失败时遗留 PDF 标为诊断产物。

用已有 PDF 解析能力真正打开并解析文档/页面，记录解析器、页数或失败错误；单看 `%PDF`、扩展名、字节数不算解析。`pdfinfo` 可提供页数/元数据，实际读取或渲染页面进一步确认内容；没有可用解析能力则标“PDF 解析未检查”，不能宣称完整成功。

记录精确字节数及 MiB。上游 >100KB 仅是发现异常输出的经验线索，不能证明不损坏，也不能据此拒绝正常小稿。明显过小/异常大时结合页数、文本、图像确认原因。

**完成条件：** 存在性、新鲜性、大小、实际解析分别有事实记录；旧稿/失败 PDF 不混入成功结果。

## 2. 文本与日志一致性

有 `pdftotext` 时提取本次 PDF 文本并保留分页边界；直接读取可用的 PDF 文本亦可，并说明能力区别。记录工具实际退出码，抽取失败不是“未发现问题”。检查 `??`（交叉引用）、`[?]`（引用）、`[VERIFY]` 与可疑拆分标记，逐处核对上下文排除文字本身的合法用法；无匹配时报告实际搜索范围。与最终引擎日志的 undefined reference、undefined citation、rerun 信号交叉核验，不能只 grep 日志代替 PDF 检查。

检查图是否真实渲染、是否出现缺图方框/占位符；文本抽取不能证明图已显示，应结合视觉。扫描型/文本不可抽取 PDF 要标能力限制，不能将空文本当零问题。

**完成条件：** 引用、交叉引用、VERIFY、图渲染逐项有证据或未检查原因，成功 build 的 warning 仍在报告。

## 3. 五项视觉检查

有实际 PDF 阅读或页面渲染能力时，检查所有页面；大文档如果只能抽样，列清已查页与未查页，整体仍为部分未检查。这是快速视觉扫描，不代替全文学术审阅。

1. 图质量：标签可读、文字清晰、颜色可区分。
2. 排版：无孤立章节标题、突兀断页或不合理大块留白。
3. 图文位置：图接近首次正文引用，记录跨多页漂移。
4. 表格：列对齐、小数精度一致，必要注释清晰。
5. 页边距：没有内容明显越界；与 overfull 日志的位置对应。

同时确认缺图占位符。缺视觉能力时以上五项分别记“未检查”，不以 pdftotext、退出码或文件存在替代视觉证据。

**完成条件：** 五项各有页面范围与发现；部分检查明确留白，不声称全稿视觉通过。

## 4. 页数与当期官方规则

先确认 venue、年份、track、投稿阶段（匿名初稿/修订/camera-ready）、主稿/补充材料类型。采用**最新适用官方作者指南与官方模板**，记录标题、URL或用户提供官方文件位置、版本/发布日期及本次核验日期、原文口径。可在本次允许的信息获取范围内核验；离线或无权访问时向用户索取官方材料并标“规则未核验”。不要套用固定 ICLR/NeurIPS/ICML 年份限额，也不要从“ML”或“IEEE”大类直接推出上限。

逐项提取：上限、references 是否计入、appendix 是否计入或需独立上传、ethics/reproducibility/limitations 等特殊章节口径、超页选项与费用、模板/字号/页边距、匿名要求、文件大小、允许的提交入口。历史上 ML 常按正文计、IEEE 常包含参考文献，但这只是待验证线索，不是规则。

取得实际总页数后，用分页文本定位 Conclusion 结束、References/Bibliography 开始、附录及伦理/可复现声明的页码，再视觉核对这些边界。标题可能不在每页前三行，也可能跨页或不叫 Conclusion；不能把 Ethics/Reproducibility 关键词自动当正文结尾。分页文本末尾空段不是新页面。

列出正文、参考文献、附录实际页码区间及共享页；同页出现结论与参考文献时，按官方口径计算，不能自称“8.5 页所以通过”。区间重叠时不直接相加。以当期规则计算计入页数和允许上限，输出“通过/超限/无法判断”及计算依据。

超限时定位最长章节、长表/图、证明等，给出具体压缩文字、压缩表格或合法移动证明至附录的建议；是否允许移入附录由官方规则与内容完整性决定。check-only 仅建议；修复模式也须明确 diff 许可。保持证据、结果、限制陈述完整，不能降规则或改边距来凑页数。

**完成条件：** 总页数、区间/共享页、官方适用依据、计数公式及差额可核验；规则或边界未明时不宣称达标。

## 5. 投稿准备

| 检查 | 证据与判定 |
| --- | --- |
| 匿名 | 匿名阶段检查作者、单位、致谢、泄露身份的自引措辞、链接、图中文字，以及 PDF 作者/标题/subject/附件等元数据；结合源稿与实际 PDF。非匿名阶段按官方要求标不适用而非删除作者。 |
| 嵌入字体 | 有 `pdffonts` 时逐行读取字体表及 `emb` 列，所有实际字体是否嵌入；`sub` 子集嵌入可与 `emb=yes` 并存。不能 `grep -v yes` 混淆列或表头；空表需解释为无文本字体/异常，不能自动通过。缺工具且无等效能力则未检查。 |
| 附录/补充 | 核对源稿 `\appendix`、分页控制及实际 PDF 边界；上游 `\newpage\appendix` 是检查线索，不机械插入。以官方模板决定是否分页、主稿内附录是否合法、是否需要单独 supplement；正文与补充不意外混合。 |
| 文件大小 | 记录真实大小并对照当期官方上传限制；上游“<50MB、最好<10MB”只是旧经验，不是默认上限。压缩建议不得损伤图质量；没有规则就标上限未核验。 |
| VERIFY 与证据 | 沿用文本检查位置并核对源稿，包括可达与条件不明章节中的标记；残留即列待核验，不能仅删除标记取得就绪。 |
| 模板、引用与入口 | 核对当期 style/class 与 journal/conference/anonymous 等选项及引用方式；例如 natbib/cite 是项目事实而非固定 venue 表。只有官方确认才报告 OpenReview、CMT、HotCRP、EDAS、ScholarOne 等实际入口；本 skill 不上传或提交。 |

**完成条件：** 所有适用项分别有状态与证据；任何失败、未知、未检查都留在投稿就绪结论中。
