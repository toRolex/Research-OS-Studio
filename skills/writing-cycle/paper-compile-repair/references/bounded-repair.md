# 有界修复的诊断顺序

仅本修复入口使用：原文 → 文件/行号 → 有证据的最小 diff → 用户认可 → 应用 → 新空目录重编译。诊断分类与孤立 `.tex` 检测见 [paper-compile diagnostics](../../paper-compile/references/diagnostics.md)。首轮基于已有可信日志或经授权的基线构建；最多三轮“应用 diff + 构建”，文献内部多遍不是多轮。连续两轮无进展时，暂停重读全部日志，复查包冲突、编码与宏；向用户提出人工复核或基于现有能力的独立分析选项，不绑定或自动调用任何 provider/插件/agent。第三轮只有尚有预算且当轮 diff 已认可才执行。

**完成条件：** 每轮有对应证据、许可、精确 diff 和构建结果；达到预算、无进展、新风险或需扩权即停止，未授权部分保持原样。
