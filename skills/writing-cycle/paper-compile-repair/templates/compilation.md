# 编译与投稿检查报告

这是供 skill 使用的字段模板，不是本次任务的报告。聊天默认；落盘需本次用户批准具体目标与新建/覆盖方式。composed 只贡献父报告，不覆盖它。所有占位值须替换为事实或“未运行/未检查/不适用 + 原因”；未发生的动作不填成已完成。

## 结论

- 模式：check-only standalone / check-only composed / 用户授权 repair
- 构建：成功 / 失败 / 未运行；PDF 实际解析：通过 / 失败 / 未检查
- 投稿就绪：通过 / 不通过 / 无法判断；依据与阻塞项
- 输入：论文真实目录、入口、源快照、dirty 基线与并发变化
- 输出：本次运行目录、新 PDF 实际路径与字节数、是否仅诊断产物；原 PDF 未替换
- 引擎、latexmk/手动链、文献后端、版本；输入闭合性、审阅范围、所选执行分级与证据
- 用户批准的临时写域、具体时间/资源预算、覆盖范围、已有落实机制与实际用量/终止原因
- 宿主路径必须声明：“宿主执行，无OS隔离保证；经审阅未发现越界操作，前后核对未发现源变化”。仅在审阅与核对事实成立时使用相应结论，异常如实替换；不声称进程无法修改原稿。sandbox 路径列实际验证的策略与限制。

## 错误、修复与警告

| 类型 | 原始消息与文件/行号或页码 | 根因证据 | 已应用 diff / 仅建议 / 阻塞 | 最终状态 |
| --- | --- | --- | --- | --- |
| 实际观察项 | 实际位置 | 可核验证据 | 检查模式“已应用”恒为无 | 不隐藏遗留 warning |

- 未定义交叉引用：实际数值与搜索范围；未检查则不用 0
- 未定义引用：实际数值与搜索范围；中间遍与最终遍分开
- VERIFY：位置与待核验证据
- 孤立 .tex：可达、候选孤立、条件不明及链路；无删除
- repair：批准/已用/剩余轮数、每轮具体 diff、两轮无进展复核、停止原因；check-only 不适用
