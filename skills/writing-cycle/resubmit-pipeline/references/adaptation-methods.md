# 转投适配方法

改编自 ARIS resubmit-pipeline 的隔离、模板迁移与页限收缩方法；事实与授权以当前材料为准。凡涉及本仓其他 Skill 的职责，以该 Skill 的当前正文为准，本文件不替代其授权。

## 旧稿保留与新目录规则

- 新目录必须与旧稿物理分离：同级新建或用户批准的其他位置，不嵌套进旧稿树，不指向旧构建输出。
- 复制用普通文件递归复制，保持相对结构；不用符号链接、硬链接，不在新入口中 `\input{../旧稿/...}`。
- 随稿复制正文、章节、宏、图、样式、文献源；旧构建产物（PDF／aux／bbl／log）不作为新稿输入，如需随附注明来源。
- 复制前后逐文件比对内容；适配前后各核对一次旧稿内容基线。出现变化即停，保留现场并报告。
- 新目录已存在、非空或解析后指向旧稿时停止；由用户改名或另选位置后重新确认。

## 模板适配

- 新入口只引用新目录内的文件；导言区按目标 venue 官方模板重建，只搬运标题、作者、摘要与章节引用等必要行。
- 图目录直接复制进新目录，不用 `\graphicspath` 指回旧稿；跨目录引用会拼出错误路径。
- 文献链跟随源稿实际配置：传统 `\bibliography` 用 BibTeX，biblatex 按其 backend 确认 Biber；样式换成 venue 要求的 `.bst`／配置，不沿用旧 venue 样式。
- 页数、匿名、字体、附录边界按官方指南口径记录；venue 未指定时做 venue-neutral 适配，页数只作讨论估计。
- 官方模板不可读时保留未核实，不用旧年份或第三方模板冒充。

## 页限收缩顺序

页数溢出时按以下顺序逐项建议，由用户逐项决定，落实仍受检查与授权约束：

1. 压缩结论与未来工作段落。
2. 收紧摘要与引言措辞。
3. 把非关键图移到附录。
4. 把证明草图与扩展讨论移到附录，正文保留定理陈述与一句话直觉。
5. 把相关工作散文压缩为比较表。

以下禁止：删除实验、删除正文定理、删除引用凑页数、改字体边距规避限制。走完仍溢出则停止，由用户决定放宽约束或换 venue。

## 匿名检查

目标 venue 双盲时检查五类泄露：表面身份（作者、机构、实验室代号）、自指措辞（“我们先前工作”）、致谢与基金信息、跨 venue 审稿引用（提及旧 venue reviewer）、内部代号与仓库链接。发现即列清单交用户决定；非双盲 venue 也可按用户要求检查。发现残留修订标记（`\todo`、彩色修订命令等）一并列出，由用户决定保留或清除。
