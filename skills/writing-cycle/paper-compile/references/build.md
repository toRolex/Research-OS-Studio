# 安全构建

入口 skill 决定是否允许修改原稿；本文件的快照与构建过程始终保持源副本不变。这里给出的命令形态不是 sandbox，也不是可以跳过检查直接执行的脚本。

## 1. 安全门

先只读检查输入路径与输出候选路径的每一层祖先，解析真实路径，记录符号链接目标。系统 `/tmp → /private/tmp` 等已解释映射可以记录后使用真实边界；项目中未知或越界链接先停止澄清。递归清点文件类型，不跟随未审核链接；拒绝设备、FIFO、socket，确认普通文件没有连到原稿的硬链接。外部资源需要明确范围及信任来源，纳入独立普通文件快照；无法在不改源路径的条件下构建就停止，不重写临时源来绕过限制。

检查版本控制状态（含 staged、unstaged、untracked）与拟访问源文件内容基线；无版本控制时保留只读内容基线供逐文件比较。dirty 不等于可回滚：读取的是用户当前稿，不 stash、不 reset、不清理。修复模式仅在用户明确确认当前 dirty 文件及拟 diff 后写入，其他改动原样保留。构建前后检测并发变化，出现变化就暂停，不自动恢复或覆盖。

核验所有可执行输入的来源与闭合性：`.tex`、`.sty`、`.cls`、文献资源及自定义宏都可能有副作用。按以下分级门选择执行路径，作者可信不等于代码已审阅：

- **受控宿主路径**：仅适用于完整审阅的自编 toy，或输入闭合且可完整审阅的纯 TeX 项目；本地宏、样式、资源均在审阅范围，发行版可信。确认没有未知 rc/脚本、Lua、shell escape、动态未知加载、越界读写或未审核链接。用户明确批准临时写域和具体预算后，才可使用普通文件快照、新空输出、真实退出码与前后内容核对执行。宿主路径的源快照保持只读使用，但不保证进程无法修改原稿。报告必须明确：“宿主执行，无OS隔离保证；经审阅未发现越界操作，前后核对未发现源变化”。后半句只在实际核对成立时使用，异常则如实报告。
- **现有 sandbox 路径**：复杂、不闭合或无法完整审阅的输入，必须使用已经存在且可验证的隔离能力，否则停止。记录实际读写/网络策略：原稿不可写，源快照与构建输入只读，仅本次输出/必要临时缓存可写，敏感目录不可见，网络禁用。未知或未核实策略不算满足门槛。

仅设置文件权限、换空目录、禁 shell escape 都不足以构成 sandbox；TeX `openout`、Lua、绝对路径、文献工具仍可能写任意位置或访问系统资源。两条路径均不新建隔离基础设施，不提升权限，不放宽远程与安装禁令。

**预算门**：在运行前让用户确认本次具体时间及资源预算、覆盖的基线/轮次/多遍子进程，并记录已有落实机制。例如用户批准整个构建最多 60 秒，须使用现有宿主执行超时能力落实；另列现有 CPU/内存/进程/输出空间限制及用户认可的适用边界。不能把一句预算说明当实际限制，不能新建 runtime 补齐。无法落实已约定的预算或不能终止超时子进程时停止；超时后不自动续跑。

项目 Makefile、latexmkrc、`.latexmkrc`、构建脚本只作为文本阅读。**不运行未知 Makefile/rc，连 `make -n` 也不运行**，解析阶段也可能执行代码。使用已安装可信工具；禁止自动安装宏包、远程依赖、自动下载和命令启动的服务。需 shell escape 的 minted 等流程只报告阻塞，已有且可信的静态资源可按原稿既有配置使用。

**完成条件：** 路径与链接、dirty 与内容基线、输入闭合性与审阅、执行分级、临时写域许可、具体预算及已有落实机制分别有证据；选择 sandbox 时另有可验证策略。任一所选路径必要条件缺失就停止，不以普通构建参数替代隔离证明。

## 2. 构建发现

- 递归发现含 `\documentclass`、`\begin{document}` 的入口；读取 `% !TeX root`、`% !TeX program`、模板说明和静态构建配置，区分主论文、supplement、示例及测试。多个入口或线索冲突时让用户选择。
- 发现 `\input`/`\include`、图文件、bibliography 与本地样式的真实路径；不要求固定 `sections/`、`figures/`、`references.bib`。检查存在性及大小写/扩展名，记录缺项。
- 引擎依据模板和包：通常 pdflatex；CJK/fontspec/定制字体可能需要 XeLaTeX，Lua 宏可能需要 LuaLaTeX。默认仅在无冲突线索时选 pdflatex，并记录推断。不能为编译通过而随意换模板或引擎。
- 文献依据源稿：传统 `\bibliography` 常用 BibTeX；biblatex 读取显式 backend，未指定时结合其配置确认 Biber；没有文献就记不适用。核验匹配引擎、latexmk（首选）及实际所需 BibTeX/Biber。缺 latexmk 时，只有现有引擎及后端足够且多遍方案已确认才可采用下节手动路径。
- 工具可用性从可信本地版本信息与帮助读取；不执行项目包装器。必需引擎/文献后端、所选执行路径的安全条件或预算落实能力缺失记“未运行”，说明用户需自行准备的组件，不执行安装。`pdfinfo`、`pdftotext`、`pdffonts` 与视觉能力为各自检查项的可选能力。

**完成条件：** 一个已确认的入口、引擎、文献链、全部所需输入、可执行工具及版本均列出；冲突或缺失有明确处置。

## 3. 普通文件快照

在获准临时空间内为本次任务创建唯一目录，分别放源快照与全新空 output；输出不能位于原稿树，也不能指向旧构建目录。递归复制已审核输入为普通文件，保留相对结构；不使用符号链接、硬链接或指回原稿的挂载来充当副本。输入中已有 PDF 图是源资源，旧编译 PDF/aux/bbl 等不能冒充本次产物；上游要求随稿提供的 bbl 如作为输入，单独注明来源。

逐文件比较快照与当前源内容，核验没有链接或特殊文件。源快照只读使用，所有生成文件、辅助文件、字体/文献缓存指向获准写域；sandbox 路径由已验证策略落实只读，宿主路径只能记录审阅与前后核对，不能承诺进程没有源稿写权限。原稿绝对路径引用、外部 `../` 路径若无法按所选路径的安全门保持原语义，则停止而不是改临时 `.tex`。构建前再次检查 output 为空。

**完成条件：** 快照内容一致、只读使用方式与保障边界明确，output 唯一且为空、源与输出物理边界分离；构建命令不会读取旧编译结果作为新结果。

## 4. 多遍编译

以下命令仅适用于**已通过分级安全门、获得临时写域与具体预算批准，且已有机制实际落实预算**的宿主或 sandbox 路径；命令本身不提供超时/资源限制，必须置于已确认的执行机制内。`ENTRY` 是审核过的入口相对路径（如 `./main.tex`，不允许选项注入），`OUT` 是该环境内的新空输出绝对路径；两者不是让 shell 求值的用户命令。工作目录为快照源根。先核对已安装版本的选项语义，环境中不带未知 TeX/latexmk 配置覆写；不设置固定全局配置。日志重定向目标必须是本次尚不存在的文件。

pdflatex：

```sh
if latexmk -norc -pdf -pdflatex='pdflatex -no-shell-escape -no-parse-first-line %O %S' -interaction=nonstopmode -halt-on-error -file-line-error -outdir="$OUT" "$ENTRY" >"$OUT/compile.stdout-stderr.log" 2>&1; then
  build_status=0
else
  build_status=$?
fi
```

XeLaTeX：同一形态用 `-xelatex -xelatex='xelatex -no-shell-escape -no-parse-first-line %O %S'` 替换 `-pdf -pdflatex=…`。LuaLaTeX：用 `-lualatex -lualatex='lualatex -no-shell-escape -no-parse-first-line %O %S'` 替换。`-norc` 对每个 latexmk 调用必带；不通过 `-r`、`-e` 或自定义依赖重新注入项目代码。XeLaTeX 后续 PDF 转换也必须遵守同一执行分级与预算；LuaLaTeX 走现有 sandbox 路径。引擎的 `-no-parse-first-line` 防止首行覆盖已确认的引擎/格式，先核对本地版本支持，不能悄悄省略防护。

上述条件分支即时保存真实退出码，即使外层 shell 启用 errexit 也能记录失败；随后在报告中原样记录 `build_status`。不接 `| tee`，不把末尾日志读取命令的成功当构建成功。保存 stdout/stderr 与 output 内的 `.log`、`.blg`、`.fls`、`.fdb_latexmk` 等实际产物。latexmk 自动完成所需多遍引擎与文献链，通常为 LaTeX → BibTeX/Biber → LaTeX → LaTeX；无文献时无需后端。核对日志中确实运行了匹配后端并完成引用收敛。

仅在 latexmk 不可用且手动链已确认时：匹配引擎带 `-no-shell-escape -no-parse-first-line -interaction=nonstopmode -halt-on-error -file-line-error -output-directory="$OUT" "$ENTRY"`；每条命令分别用上述 if/else 保存退出码与独立日志，任一步非零立即停止该链。BibTeX 在 output 中对实际 jobname 运行，使用已审核且仅指向只读快照/可信本地发行版的文献与样式搜索路径；Biber 对实际 `.bcf` 使用匹配输入/输出目录，仅本地资源。然后引擎再跑两遍；仍要求 rerun 或引用未收敛则报告，不无界追加。复杂多文献单元/自定义依赖若无法安全复现，记未运行或不支持，不猜命令。

命令完成后检查源稿和快照源内容基线；任何变化都是边界异常，停止后续执行，保留现场并报告。不执行 `latexmk -C` 或其他 cleanup，不覆盖原 PDF，不删除失败日志。超时、被信号终止或资源限制应记录真实终止原因；输出 PDF 存在不能将失败改为成功。

**完成条件：** 每个实际子命令退出状态与日志留存、文献链和收敛可核验、输入无变化；构建失败/未运行原因与本次产物明确分开。
