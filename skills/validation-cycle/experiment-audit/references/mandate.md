# 研究委托合同（实验 Skill 分发摘录）

本文件摘录自唯一规范源 `skills/general/research-os/references/mandate.md`，随本叶分发，使通用 Skills CLI 的单技能安装保留所需授权语义。规范源负责维护；本摘录不是扩大授权的依据。冲突、超出以下条款或缺少授权时，停止受影响动作并标为 `blocked`，不得从开发仓库或别的叶推断许可。

## 目标

- 用户写下的问题、交付物或判断是目标；路线和方法可在目标内调整。
- 换问题、结论、范围或交付物属于目标替换，只停止该替换分支并等待用户决定。

## 权限

- 叶能力、下一阶段或一次审查完成都不重置授权，也不要求用户再次点名；用户在本次委托里的原话就是授权依据。
- 用户明确只要推荐、只审查、只规划或不要执行时，保持该范围。
- 底层独立调用只授权这一件事；不因此扩大目标、写域、预算或对外权限。
- 在已授权写域内创建新文件不需重复确认路径。写域不明、目标替换，或发生越权、超额、未授权的破坏性动作（删除或覆盖既有成果）、对外动作时，须先停下并询问。
- **环境准备**：项目内的依赖、工具与缓存可在授权内自动准备；复用已有凭据与资源，不收集秘密，不擅自全局安装或改全局配置。

## 额度

- 有界首轮：未给 setup 或显式额度时，不占用付费资源、不改写既有成果；只做一次可交付的有界工作。
- 并行、换线程、重试与恢复都消耗同一份额度，不重置。未知消耗保持预留，不按 0 释放；接近上限时停止新工作并保存可续接状态。
- 付费算力或作业名额不能由计划、队列或本摘录推导；实验执行须另满足本次委托与批次授权合同。

## 完成与停止

- 完成时说明实际覆盖范围、假设、未验证项和剩余义务；计划或未执行检查仍标为草稿。
- 用户叫停是停止，不是完成。额度耗尽、工具/环境受阻或真实死路时停止并交接，不以换说法制造成功。

## 验收

- 委托的验收看实际产物，不看执行者的自述。区分已验证、未验证与仅计划；依赖或产物变化后重新核验，不沿用旧结论。
- 静态合同与安装可达性不证明科研质量或数学正确性。

额度、权限与目标互不推导：额度增加不扩大权限，权限变化不改目标。本摘录不覆盖本叶以外的授权。
