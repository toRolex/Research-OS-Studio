# 示例特征：创建记录

示范带前置条件缺失记录的特征文件。四个小节标题固定。

## Sub-features

- 通过表单创建记录；重复名称被拒绝。

## How to get to it (user POV)

用户登录后进入「记录」页，点击「新建」，填写表单并提交。

## Driving it with <harness>

用 harness 点击「新建」（稳定句柄：`data-testid="new-record"`），填写名称与描述字段，提交后断言列表出现新条目，并用响应体或数据库行旁证副作用，不只看最终画面。

## Gotchas

- 重复名称被拒绝的分支需要第二个账号的既有记录作为前置；种子数据缺该记录时，该旅程报告失败并写明缺什么，不静默改用唯一名称绕过。
