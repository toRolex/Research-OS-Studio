# 示例特征：搜索

示范一个用户可见特征的映射文件写法。四个小节标题固定，正文全部取自真实调查发现，不留占位符。

## Sub-features

- 关键词搜索；按标签过滤。

## How to get to it (user POV)

用户在首页输入框键入关键词后回车，或点击标签云中的标签。

## Driving it with <harness>

用 harness 对搜索框填写关键词并回车（稳定句柄：搜索框的 ARIA 标签 `search-query`），等待结果列表出现，断言首条结果标题包含关键词。

## Gotchas

- 搜索索引在种子数据导入完成后才可用；种子未就绪时本特征旅程如实报告失败，并把原因与等待方式记录在这里，不削弱旅程换取通过。
