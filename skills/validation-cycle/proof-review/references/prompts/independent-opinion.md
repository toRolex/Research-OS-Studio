# 独立意见

仅在用户为本轮明确请求第二意见时使用。请求意见不等于同意远程发送。审计路径见 [提示模板](../dispatch-prompts.md)。

```text
为当前单一 obligation 准备或取得独立审查。

本轮目录：<本轮目录>
输入：精确目标、定义与权威来源，以及本轮待审候选证明及其实际位置。
本地尝试存在时读 local-proof.md；候选来自回传时读 external-answer.md 及已有
审计记录，不因用户跳过本地尝试而要求补造 local-proof.md。

要求：
- 先对待审候选完成本地子目标检查；跳过证明尝试不等于跳过自查。
- 阅读 proof-audit-rubric.md、independent-review.md。
- 只用本轮明确授权的现成路线；先确认外发材料、实际模型和费用边界。
  没有授权或可用路线时交付手动包或询问用户，不安装、不自动替代或重试。
- 本地填齐独立审查完整 prompt，远端所需检查项须内联，材料显式分隔。
- 原始返回存为 independent-review.md。
- 本地核验问题位置、前提和反例，再整合到 audit.md。
- 按 audit-output-contract.md 分开自查、原始外部判决、验证结果及独立性。
完成条件：有效意见已核验并记录；或明确说明未取得独立意见及阻断原因。
自查不能冒充独立第二意见，未知模型不能冒充跨家族证据。
```
