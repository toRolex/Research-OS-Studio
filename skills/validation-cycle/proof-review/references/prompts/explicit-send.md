# 显式代执行

只由获授权执行者使用：当前用户请求或仍有效的原委托须明确覆盖本次发送、现成路线、外发材料与费用。仅批准一次时不推导后续调用；已覆盖有限重试时按[独立意见](../independent-review.md)核对后继承。只读 reviewer 不执行发送或保存文件。模板文字本身不是授权。审计路径见 [提示模板](../dispatch-prompts.md)。

```text
授权依据：[用户原话/有效原委托来源、范围与有效期]。
调用边界：[已授权次数/有限重试、已消耗与在途预留、剩余额度]。

本轮目录：<本轮目录>
路线：[已存在、可用且明确授权的具体路线]
材料与费用范围：[允许外发文件、模型、操作及费用上限]

要求：
- 重新核实上述授权和现成路线；缺一项则停下询问或给用户手动包。
- 不从模板发起 Skill 调用，不安装工具、不创建凭据。
- browser-prompt.md 作为精确模型提示，source-manifest.md 作为来源约定；
  确认必要来源完整，排除秘密及无关内容。
- 操作失败不静默改路线；浏览器失败不是 API 付费授权。
- 若原委托只覆盖一次，不重试或追加对话。原委托明确覆盖有限重试时，
  仅在前次响应已明确返回、实际身份符合授权、同一路线/材料范围且仍有
  已授权次数与费用余额时继续；所有尝试累计计费，不因此重复索权。
- 不借重试切模型、改路线、扩大材料或费用范围。授权缺失/过期/越界、
  身份未知或不匹配、额度耗尽时停止；超时/传输失败导致是否已执行或
  在途状态不明时不盲目重发，说明不确定性并等待用户决定。
- 完整答案保存为 external-answer.md，按本轮实际发出的 prompt 检查结束标记
  和完整性；新交接默认 END_EXTERNAL_OUTPUT，不追溯改变旧答案的标记。
- 未通过完整性检查时保留实际收到的内容，说明缺失，不补造；后续发送
  仍须满足上述有限重试条件，未满足时不重发。
完成条件：本次实际操作与完整/不完整返回如实记录，或明确阻断；
取得返回后进入本地审计，不把发送成功当作证明成功。
```
