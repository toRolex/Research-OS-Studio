# 本地证明

先在本地尝试当前证明，再考虑外部交接。审计路径见 [提示模板](../dispatch-prompts.md)。

```text
先在本地尝试当前证明，再考虑外部交接。

本轮目录：<本轮目录>
目标：[精确定理、引理、反证、反例或诊断；一个有界 obligation]
输入：
- [来源路径]：[权威角色及允许使用范围]
本轮边界：[时间/尝试预算、允许文件及完成目标]

要求：
- 检查假设、定义域、边界情况、量词及所引定理的全部前提。
- 把完整尝试写到 local-proof.md，不停在难度探测。
- 成功时先查正确性，再编辑表达和记号，最后写 report.md。
- 按 notation-audit.md 的触发条件执行记号审查；适用时完整执行并将固定
  七行计分表记录到 audit.md，落实其中阻断规则与警告；否则注明不适用原因。
- 用归纳法时，展示核验所需的基础情形、归纳假设及归纳步骤。
- 非平凡推导采用目标优先结构：声明目标、论证即时子目标为何充分、
  从具名输入推导各子目标，再合并回到原目标。依真实依赖排序，
  检查循环及反向蕴含；一步证明不强加框架。
- 未解决时定位最小缺口，不调用远端或创建远程项目。
- 到达预算即停止：报告有效片段、反例、缺口或缺失输入，不滚动扩大任务。
完成条件：完整尝试和自查已记录；report.md 明确当前结论、证据及未解决项。
```
