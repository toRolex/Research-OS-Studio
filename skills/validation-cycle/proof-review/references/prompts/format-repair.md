# 格式修复

在正确性审查前，只修复复制造成的格式损坏。审计路径见 [提示模板](../dispatch-prompts.md)。

```text
在正确性审查前，修复 <本轮目录>/external-answer.md 中复制导致的格式损坏。

要求：
- 保持证明顺序、标签、主张、常数、假设及定理状态。
- 按实际发出提示中请求的结束标记检查；新提示默认 END_EXTERNAL_OUTPUT。
  请求过的标记缺失则说明可能截断；旧答案不要求换成新默认标记。
- 检查显示数学分隔符配对及可疑空行。
- 只修复无歧义的转义花括号损坏，例如 \left{ → \left\{、\right} → \right\}。
- 仅在原作用明确时移除网页复制残留分隔线；否则在 audit.md 标注。
- 扫描损坏算子、游离 Markdown 标记、错误右定界符。
- 歧义损坏写入 audit.md，不猜测；非平凡格式修复记录前后及理由，
  保留原始片段可辨认。数学内容的变更只能作为另行建议。
- 实质清晰度和符号改写放在正确性核验后的 report.md，不改原始证据。
完成条件：格式修复有据、完整性或歧义已标明；随后才开始正确性审计。
```
