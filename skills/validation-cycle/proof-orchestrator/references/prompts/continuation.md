# 续轮

从旧轮材料继续当前委托内的一个窄子目标。续接、暂停与恢复由 `/research-os` proof 配方控制；审计路径见 [提示模板](../dispatch-prompts.md)，需要外部包时用 [手动交接](manual-handoff.md)。

```text
从旧轮材料继续一个新的窄子目标。

旧轮目录：[只读路径]
本轮目录：<本轮目录>，必须为新目录
续轮请求：[一个窄 obligation]
当前委托：[原目标、已授权材料/写域、剩余额度与停止条件；不新建或重置]

要求：
- 读取旧轮存在的 report.md、audit.md、local-proof.md、source-manifest.md、
  handoff.md 及相关 next/redo/continuation 文件；只读，不覆盖旧轮。
- 在本轮 materials.md 或 report.md 记录旧轮标识和实际读取的精确文件。
- 仅把有审计依据、且前提仍适用于当前目标的结论作为已证依赖；
  猜想、被否定结论、未解决项分别标注。external-answer.md 仅为原始证据。
- 复用稳定本地来源并保留出处，不覆写旧轮来源；材料变更重新核对。
- 默认先本地尝试当前目标；用户明确跳过尝试或只要交接包时，记录本轮
  范围决定，按手动交接模板准备新的外部提示。
- 仍需求助时使用新 browser-prompt.md 及新对话；只有来源集匹配时
  用户才可复用原远程项目。当前研究委托不会授权其中未包含的上传、费用或操作。
- 不为已覆盖的阶段或重试重复索权；达到剩余额度、停止条件或需要扩大目标/写域时，返回 `/research-os` 按研究委托处理。外部发送仍须通过相应具体决定门。
完成条件：当前目标及继承证据清楚，本地结果或最小缺口已记录，旧轮未改动，且总额度未被重置。
```
