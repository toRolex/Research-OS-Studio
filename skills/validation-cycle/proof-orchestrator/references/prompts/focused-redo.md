# 聚焦重做

从已审计缺口准备新的手动重做包，不启动无限迭代。来源核对、数据分隔和结束标记用 [手动交接](manual-handoff.md)。审计路径见 [提示模板](../dispatch-prompts.md)。

```text
从已审计的缺口准备新的手动重做包，不启动无限迭代。

输入：旧轮 external-answer.md、audit.md、source-manifest.md；若曾执行本地尝试
且文件存在，再读 local-proof.md。用户跳过尝试时，直接依据返回原文与审计缺口重做。
新本轮目录：<本轮目录>；旧轮只读。

要求：
- 只问已审计的缺失步骤或无效推理；保留原命题和假设。
- 记录旧轮来源、具体缺口及本轮新的有界目标和预算。
- 在新目录写 browser-prompt.md、source-manifest.md、handoff.md，
  复用手动交接模板的来源核对、数据分隔和结束标记约定。
- 默认交给用户手动操作，新对话不隐含旧轮上下文或许可。
- 用户未明确授权本次执行器发送时，停在交接包；历史授权不能继承。
完成条件：聚焦问题及来源齐全、包已交用户，或阻断已说明；停止等待，
不自动继续下一轮或扩展为整个定理的求解。
```
