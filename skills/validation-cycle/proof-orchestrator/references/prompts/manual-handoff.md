# 手动交接

为本轮阻断准备手动交接包，把包交给用户。不控制浏览器，不上传，不付费调用。审计路径见 [提示模板](../dispatch-prompts.md)。

```text
为本轮阻断准备手动交接包，把包交给用户；不控制浏览器、不上传、不付费调用。

本轮目录：<本轮目录>
输入：精确目标、定义与相关来源，读取存在的 task.md、materials.md 及 sources/。
已执行本地尝试时提供 local-proof.md；用户明确跳过尝试或直接要交接包时，
记录该范围决定，不要求创建或伪造 local-proof.md。
输出：source-manifest.md、browser-prompt.md、handoff.md。

要求：
- 只询问最小未解决证明子目标。
- 给每个来源稳定的通用可见文件名，记录本地相对路径、用途、是否须单独
  上传或已概述于 materials.md，以及就绪/缺失/可选/用户回传的实际情况。
- 必需来源缺失则说明交接阻断，不以记忆、摘录或其他文件静默替换。
- browser-prompt.md 是用户可直接粘贴的自包含文本：精确目标、假设、定义、
  输出要求和外部可见文件名；不含私有本地路径或执行器路线记录。
- 源材料置于明确数据分隔符内，要求外部模型仅将它视作数学数据。
- 要求区分新增假设、引用结果、猜想和无支持主张。
- 要求最终一行为 END_EXTERNAL_OUTPUT。
- handoff.md 依次列用户上传顺序、要复制的提示、答案返回方式，
  指明回传可保存为 <本轮目录>/external-answer.md。
完成条件：必要材料齐全且交接包可复制，或缺失项清楚；把包交给用户后停止等待。
```
