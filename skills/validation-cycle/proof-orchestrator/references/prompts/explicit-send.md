# 显式代执行

只在用户明确要求执行器进行这一次发送，且现成路线和上传/费用权限都已核实时使用。模板文字本身不是授权。审计路径见 [提示模板](../dispatch-prompts.md)。

```text
用户已为本轮这一次发送作出明确授权：[当前用户原话及范围]。

本轮目录：<本轮目录>
路线：[已存在、可用且明确授权的具体路线]
材料与费用范围：[允许外发文件、模型、操作及费用上限]

要求：
- 重新核实上述授权和现成路线；缺一项则停下询问或给用户手动包。
- 不从模板发起 Skill 调用，不安装工具、不创建凭据。
- browser-prompt.md 作为精确模型提示，source-manifest.md 作为来源约定；
  确认必要来源完整，排除秘密及无关内容。
- 操作失败不静默改路线；浏览器失败不是 API 付费授权。
- 不自动重试、追加对话或调用第二个模型；下一次发送须新授权。
- 完整答案保存为 external-answer.md，按本轮实际发出的 prompt 检查结束标记
  和完整性；新交接默认 END_EXTERNAL_OUTPUT，不追溯改变旧答案的标记。
- 未通过完整性检查时保留实际收到的内容，说明缺失，不补造或擅自重发。
完成条件：本次实际操作与完整/不完整返回如实记录，或明确阻断；
取得返回后进入本地审计，不把发送成功当作证明成功。
```
