# 证明符号审计

正确性检查后、完成 `<本轮目录>/report.md` 前使用。用户问符号、输出以定理为主，或某一步含至少五个非标准符号时，完整执行。阈值是表达编辑标准，不是数学定律；确实降低总复杂度的超阈值记号可保留，但须逐项解释。

正确性分类见[证明审计准则](proof-audit-rubric.md)，记录格式见[审计输出约定](audit-output-contract.md)，本地及回传分支见[提示模板](dispatch-prompts.md)。

## 必需清单

先从定理陈述、算法更新和最终结论确定语义中心：状态变量、策略或分布、算子、目标函数及其依赖方向。记录每个非标准符号的含义、作用域、首次定义及后续使用次数；分类为 `core`、`keep`、`localize`、`inline`、`rename`、`delete`。排除约束变量、求和下标及标准算子。

在 `audit.md` 按下列标签和顺序原样填入七行，不用“重载符号”“无关链”或文字摘要替换。分母为零时写 `0/0 (N/A)` 并说明无适用对象，不编造百分比。

```text
Core semantic objects retained: <retained>/<declared> (<percent>)
Undefined symbols: <count>
Symbol collisions: <count>
One-use definitions: <count>/<all new symbols> (<percent>)
Maximum parallel representations of one object: <count>
Maximum alias-chain depth: <count>
Maximum active nonstandard symbols in one proof step: <count>
```

## 阻断规则

把证明作为可用结果呈现前，核心对象保留率须为 100%，未定义符号和冲突均为零；没有适用核心对象时明确解释 N/A。

- **核心对象丢失**：改写删除、隐藏或替换定理的核心状态、策略或分布、算子、目标或依赖方向。坐标图不是其所参数化对象的替代品。
- **未定义符号**：含义及作用域尚不明确便出现。
- **冲突**：同一字形在整个材料中表示不同对象；不同下标不能修复基础含义变化。

优先保留既有或标准含义，另一处重命名或删除。不能依赖遥远的章节边界消解冲突。

只有降低计算复杂度时才保留局部坐标；首次使用说明到核心对象的映射，并用核心对象重新表达每个主要定理、流或最终界。字形更少不能补偿数学接口的改变。

不能靠补入貌似合理的数学降低阻断计数。可重命名或内联有依据的表达式，但不可发明定义域、假设、导数恒等式、符号关系、定理前提或定义。权威材料未能解决时，保留计数，在报告中说明证明尚不可用。

## 警告阈值

### 定义收益

新符号至少满足一项才保留：

- 在后续至少三个公式中出现；
- 同时出现在定理陈述和证明中；
- 命名了后文会比较、变化或引用的对象。

约 12 字符或更短且最多出现两次的表达式宜内联。若展开会遮蔽长推导，可保留局部缩写，但作用域随该推导结束。

### 一次性定义

- 良好：不超过新符号的 10%。
- 警告：超过 10% 且不超过 20%。
- 较差：超过 20%。

一次性定义仅在紧接着的一句或一个公式中使用。不计约束变量和标准局部占位符。

### 并行表示

- 良好：同一对象至多两个持久表示，例如概率及其 logit。
- 较差：三个或更多持久表示。

第三种表示仅可留在一个局部推导内，小节结束即移除。

### 别名链深度

- 良好：一层，符号直接引用原始量。
- 警告：两层。
- 较差：三层或更多。

例如 `K := M+2`、`lambda := a/K`、`S := lambda x+b`，若末级仅服务一个不等式，应展平链条。

### 活跃符号负载

统计读者跨一个定理陈述、证明段落或连续公式链必须记住的非标准符号。

- 良好：至多 8。
- 警告：9–12。
- 较差：超过 12。

超过 8 时拆分论证、局部化定义或内联临时别名；不能为降低计数删除证明步骤。

### 定义距离

在首次使用前的段落内定义符号。局部作用域止于小节边界。除定理声明的全局记号外，读者不应跨章节寻找定义。

## 九步改写顺序

1. 识别并固定语义中心和依赖方向；完成条件：核心对象清单与原命题一致。
2. 修复未定义符号与冲突；完成条件：有来源的修复完成，未解决者明确保留为阻断。
3. 删除未使用的非核心符号；完成条件：每项删除都不影响核心对象。
4. 内联一次性定义，展平别名链；完成条件：剩余超阈值项有具体理由。
5. 限制各对象的持久表示数量；完成条件：第三表示被局部化或记录理由。
6. 拆分活跃符号仍超过 8 的步骤；完成条件：推理依赖保留，剩余负载警告有解释。
7. 把坐标结论映回核心对象；完成条件：每个主要结论恢复原定理接口。
8. 复查全部代换和定理依赖；完成条件：等价性、定义域和引用前提均核对。
9. 最后删除冗余文字或显然代数；完成条件：每个非显然转换仍可验证，七行计分表已更新。

若更短的改写需要新增数学关系，输出诊断而不是伪装修好的证明。新名称确有数学含义时可保留较长表达。正确性及可验证的非显然步骤优先于低符号计数。
