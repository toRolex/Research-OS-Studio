# 数学义务与全局闭合

## 六份相互关联的自然 Markdown 账本

1. **Dependency DAG**：节点为定义、假设、引理、定理，边为“使用”。合并所有涉及章节后检查有向环，包括引理 A 使用推论 B、B 实际依赖 A 的语义循环；局部无环不能推出全局无环。标出影响链和每条引用的位置。
2. **Assumption ledger**：每个结果列全部声明假设、实际使用的最小假设集、每次应用处的假设与原文声称解除位置。没有位置写“无解除位置”，不是凭抽取就判错误；审查意见另记。被当作假设的未验证导入显式标出，不算已证明。
3. **Typed symbol table**：每个符号列类型、定义域、维数、正性/对称性/可测性等结构、参数依赖与定义位置。例如 κ 是依赖 (d, α_t, Σ, μ) 的 (0,1) 标量；u* = C⁻¹m 属于 ℝᵈ 还要求 C 可逆；B^even 是 (L+1)×(L+1) 对称 PSD 矩阵；Ψ_v: ℝ→ℝ 的解析域和奇偶性必须明确。跨章节同符号异义、缩放约定变化都要提出问题。
4. **Canonical quantified statements**：保留原命题并列显式形式。例如 ∀K≥3，∀π∈Π_K^{ms,∘}∖E_K，∃κ₀>0，∀κ∈(0,κ₀)：h_act^{(K,π)}=Θ(κ^{α_K^act})，对 π 的紧子集一致。列 κ₀ 对 K、π、d 的依赖；无法确定时标“UNCLEAR，需要用户澄清”，不自行选择量词。
5. **Micro-claim inventory**：每个非平凡步骤编号，以“上下文 ⊢ 目标；规则；侧条件；声称解除位置；审查结论”记录。例如 MC-17 在 Lemma 3.1、κ<κ₀、Zκ 至 2m+2 阶矩有界下证明 P̂₀ 正定，所用规则为支持集上单项式线性无关；原点邻域正密度是额外侧条件，弱收敛本身是否能证明须审查。所有 clearly、it follows、standard arguments 与 WLOG 都展开义务。
6. **Limit-order map**：每个 O、o、Θ、≲、~ 列极限变量、固定参数、联合/迭代极限次序、一致性域、隐常数依赖。例如 h_act=Θ(κ^α) 是固定 K、κ→0、对 Π_K 紧子集一致；τ_act~(b/a)n 是固定 κ,K,π 且 x_K≪1 的 n→∞。点态不能直接提升一致，概率/几乎处处/L²/期望/高概率之间转移均需证明。

完成标准：全局每个非平凡推理都有上下文、目标和侧条件，图与账本相互定位；抽取完成仅表示结构完整，不是证明正确。

## 双轴与严重度

证明状态：INVALID（原陈述为假）、UNJUSTIFIED（现证明不足）、UNDERSTATED（需加强假设）、OVERSTATED（需减弱结论/限定）、UNCLEAR（符号或定义含混）。影响：GLOBAL（主定理或核心链）、LOCAL（旁支）、COSMETIC（表述）。

| 严重度 | 上游对应 |
|---|---|
| FATAL | INVALID + GLOBAL |
| CRITICAL | INVALID + LOCAL，或 UNJUSTIFIED + GLOBAL |
| MAJOR | UNJUSTIFIED + LOCAL，或 UNDERSTATED/OVERSTATED + GLOBAL |
| MINOR | 不改变数学命题的清晰性、符号与维数记账 |

不能精确落入上述组合时，保留两轴并要求 proof-review 解释严重度；不自动把影响命题的假设缺失降成 MINOR。

## 问题分类

| 类别 | 要找的问题 |
|---|---|
| UNJUSTIFIED_ASSERTION | 无推导或引用的断言，例如 Hessian 自动分成 Gram 块 |
| UNPROVEN_SUBCLAIM | clearly/对称性掩盖未证子引理，例如交叉项消失 |
| QUANTIFIER_ERROR | ∀/∃ 次序错、缺少 sufficiently small 条件 |
| IMPLICATION_REVERSAL | 把 A⇒B 当 B⇒A，或只证明等价的一向 |
| CASE_INCOMPLETE | 奇异协方差、零权重、非唯一极值点等缺失 |
| CIRCULAR_DEPENDENCY | 引理借用了依赖自身的定理/推论 |
| LOGICAL_GAP | 前提不足以推出下一步，例如 B=Θ(1) 未分析 W 就推出 β_K=0 |
| ILLEGAL_INTERCHANGE | 极限、期望、导数、积分交换未合法化 |
| NONUNIFORM_CONVERGENCE | 点态代一致、交换 sup 和极限 |
| MISSING_DOMINATION | 援引 DCT 却无可积支配函数 |
| INTEGRABILITY_GAP | 使用 E|X|ᵖ 却无有限矩依据 |
| REGULARITY_GAP | 可微、Lipschitz、凸性未经建立 |
| STOCHASTIC_MODE_CONFUSION | 混淆 a.s.、概率、L²、期望等模式 |
| MISSING_DERIVATION | 模型到风险或 B,W 的表达式没有推导 |
| HIDDEN_ASSUMPTION | 暗用 Gaussian 等未声明条件 |
| INSUFFICIENT_ASSUMPTION | 声明假设允许反例，如矩约束允许两点分布 |
| DIMENSION_TRACKING | d,n,K 依赖不明，维数藏在 κ 中 |
| NORMALIZATION_MISMATCH | 原始与重标度坐标不一致 |
| CONSTANT_DEPENDENCE_HIDDEN | C 暗依赖 d,n,K 却当通用常数 |
| SCOPE_OVERCLAIM | 结论范围超出推导覆盖范围 |
| REFERENCE_MISMATCH | 引用结果在应用处没有满足其全部条件 |

## 常用定理侧条件

以下是检查起点，实际采用的定理版本及其全部条件优先；不是凭关键词就完成证明。

| 结果 | 必须明确核查 |
|---|---|
| DCT | 几乎处处点态收敛、共同可积支配函数，给出函数及可积证明 |
| MCT | 非负、单调递增、可测性 |
| Fubini/Tonelli | 产品可测性；Fubini 绝对可积，Tonelli 非负；适用测度空间条件 |
| Leibniz 积分求导 | 采用版本的连续/可微条件及导数的共同可积支配；变动端点项如适用 |
| 隐函数定理 | 连续可微、指定点 Jacobian 非奇异、局部域 |
| Taylor 余项 | 所需可微阶数、Lagrange/积分余项的具体形式与界 |
| Jensen | 凸性、随机量及函数值所需可积性、定义域 |
| Cauchy–Schwarz | 正确内积空间、两因子平方可积或对应范数有限 |
| Weyl/Davis–Kahan | 对称/Hermitian、扰动范数界、所用版本的谱间隙等条件 |
| 解析延拓 | 连通解析域、恒等定理要求的聚点等条件 |
| WLOG | 所声称对称下问题不变、变换保留假设且还原无损 |

对每次应用逐条给出位置或证明；只在引理声明处核查一次不足以覆盖后续应用。

## 反例先行与回归

针对所有关键引理、FATAL/CRITICAL/MAJOR 问题，以及新增不等式、可辨识/唯一性、曲率/PSD/强凸、一致性与收敛模式升级逐项尝试：

- 降维：d=1 或 2，K=2，小 n，检验命题确实允许这些值。
- 退化：奇异协方差、极小/零权重、均值重合、相同混合分量、非唯一极值。
- 极端分布：两点 ±a、有界但不满足所声称的统一次高斯约束的分布族、重尾。单个有界随机变量本身是次高斯，不能照搬上游“bounded non-subGaussian”字面制造伪反例。
- 对抗缩放：让忽略项超过主项，检查多参数极限次序与一致性域。
- 数值证伪：只在工具/资源已批准时，将引理写成可计算函数，在小域搜索或优化，保留参数、精度、方法、输出和误差。未批准时使用解析构造。

每次尝试记录满足的全部假设、测试结论、推导、成功/失败及原因。只有代数验证确实满足原假设且违反原结论才叫“反例已确认”；浮点违例或未验证构造叫“候选”。没有找到反例不算证明。修改后对所有下游引理重跑适用候选，失败路线留存。

## 全局闭合

- **精确终点**：证明末端得到的量词、结论、常数、参数域和一致性恰好覆盖最终命题。
- **义务全清点**：每个 DAG 节点均有完整证明或用户明确批准且写入适用命题的假设；每条应用边有逐项侧条件解除。未验证导入单列，不假装已证。
- **覆盖**：各分支覆盖全定义域、边界与退化，重叠分支相容；穷尽性有依据。
- **归纳**：基例、归纳步、归纳假设适用对象、严格递减良序量/正确递增索引与终止依据。
- **WLOG**：每次约化都有可逆或无损性微命题，不能靠一句“不妨”。
- **Assumption delta**：逐条比较修前/修后条件、强弱关系、必要理由、用户决策、主定理及下游应用与已知重述的同步位置；未使用假设也注明。
- **回归**：合并改动后重算全局 DAG（含语义环）、符号类型一致性、修改下游反例集，纳入新引理与新侧条件。

闭合必须由 proof-review 的实际审查支持；执行器的自检是送审准备。任何已知受影响的下游无法完整读取或获准同步，则停止，不能以缩小报告范围掩盖破坏。
