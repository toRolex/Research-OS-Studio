# 六份账本

## 六份相互关联的自然 Markdown 账本

1. **Dependency DAG**：节点为定义、假设、引理、定理，边为“使用”。合并所有涉及章节后检查有向环，包括引理 A 使用推论 B、B 实际依赖 A 的语义循环；局部无环不能推出全局无环。标出影响链和每条引用的位置。
2. **Assumption ledger**：每个结果列全部声明假设、实际使用的最小假设集、每次应用处的假设与原文声称解除位置。没有位置写“无解除位置”，不是凭抽取就判错误；审查意见另记。被当作假设的未验证导入显式标出，不算已证明。
3. **Typed symbol table**：每个符号列类型、定义域、维数、正性/对称性/可测性等结构、参数依赖与定义位置。例如 κ 是依赖 (d, α_t, Σ, μ) 的 (0,1) 标量；u* = C⁻¹m 属于 ℝᵈ 还要求 C 可逆；B^even 是 (L+1)×(L+1) 对称 PSD 矩阵；Ψ_v: ℝ→ℝ 的解析域和奇偶性必须明确。跨章节同符号异义、缩放约定变化都要提出问题。
4. **Canonical quantified statements**：保留原命题并列显式形式。例如 ∀K≥3，∀π∈Π_K^{ms,∘}∖E_K，∃κ₀>0，∀κ∈(0,κ₀)：h_act^{(K,π)}=Θ(κ^{α_K^act})，对 π 的紧子集一致。列 κ₀ 对 K、π、d 的依赖；无法确定时标“UNCLEAR，需要用户澄清”，不自行选择量词。
5. **Micro-claim inventory**：每个非平凡步骤编号，以“上下文 ⊢ 目标；规则；侧条件；声称解除位置；审查结论”记录。例如 MC-17 在 Lemma 3.1、κ<κ₀、Zκ 至 2m+2 阶矩有界下证明 P̂₀ 正定，所用规则为支持集上单项式线性无关；原点邻域正密度是额外侧条件，弱收敛本身是否能证明须审查。所有 clearly、it follows、standard arguments 与 WLOG 都展开义务。
6. **Limit-order map**：每个 O、o、Θ、≲、~ 列极限变量、固定参数、联合/迭代极限次序、一致性域、隐常数依赖。例如 h_act=Θ(κ^α) 是固定 K、κ→0、对 Π_K 紧子集一致；τ_act~(b/a)n 是固定 κ,K,π 且 x_K≪1 的 n→∞。点态不能直接提升一致，概率/几乎处处/L²/期望/高概率之间转移均需证明。

完成标准：全局每个非平凡推理都有上下文、目标和侧条件，图与账本相互定位；抽取完成仅表示结构完整，不是证明正确。

问题分类、双轴、严重度、定理侧条件和反例是否成立，只按 proof-review 的 [数学审查规则](../../proof-review/references/review-rules.md)。整体闭合只按 proof-review 主文件。本文件不另列一套。Assumption delta 仍记在修复记录：修前/修后条件、强弱、用户决定、下游同步位置。已知受影响的下游读不到或未获准同步，则停止，不以缩小报告范围掩盖破坏。
