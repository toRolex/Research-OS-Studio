# 重述回归（仅 --restatement-check）

用户明确 opt-in 才做这篇额外扫描，顺序在全局闭合之后、停止/交付之前。不替代命题—结论核对，也不替代本轮已知下游同步。

六类漂移、扫描位置和报告字段只在 proof-review 的 [跨位置重述回归](../../proof-review/references/restatement-check.md)。按那份执行，不在这里重述。

本侧只加修复边界：发现只作建议，不自动改文件，也不单凭漂移改证明结论。漂移破坏推理时，由 proof-review 在普通问题里解释影响。文件不可读、标签歧义或范围不够时，记录「重述检查不可用」、缺口和已查范围；空发现不是「无漂移」。扫描本身不可用不挡住其它步骤；它暴露的下游不同步或数学阻塞仍按主流程停止。
