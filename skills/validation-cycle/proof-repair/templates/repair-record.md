# 修复契约与累计记录模板

按实际任务填充自然 Markdown；本模板不是默认输出路径，也不自动授权创建文件。记录需保留完整推导与审查原文，不以以下表格代替内容。

## 用户确认的契约

- 原文输入及可读资源：绝对路径/获准来源，已读范围、版本或原文定位，缺项。
- Scope：目标与排除项、全部上下游边界。
- 原命题全文：
- 显式目标：量词、域、参数、极限次序、常数、一致性。
- 假设全文与不变量：
- 允许写入：逐文件绝对路径、唯一锚点/环境/段落范围、创建或修改、保留标签；无授权写“不写”。
- 记录文件授权：
- 工具、网络/外发、数值/符号资源预算与审查授权：
- 编译独立授权：现有工具、入口、命令、工作目录、次数/时间、输出和副产物范围；默认未授权。
- 可选 LaTeX 审计报告授权与路径：默认不输出；编译另批。
- 用户确认的最大轮数：建议最多 3；当前已用轮数。
- 深修复/重述回归：用户是否明确 opt-in。
- 用户实际确认内容与尚待决定项：
- 停止条件与冲突处理：

## 基线与义务

附六份账本完整内容；每项区分原文声称位置、执行器自检和 proof-review 实际结论。列出所有标准问题与原始审查反馈全文。

## 第 N 轮：修复项

### Fix N：标题

- Issue：编号、CATEGORY、描述。
- Severity：FATAL / CRITICAL / MAJOR / MINOR。
- Status：INVALID / UNJUSTIFIED / UNDERSTATED / OVERSTATED / UNCLEAR。
- Impact：GLOBAL / LOCAL / COSMETIC。
- Fix strategy：ADD_DERIVATION / STRENGTHEN_ASSUMPTION / WEAKEN_CLAIM / ADD_REFERENCE。
- Location：绝对路径、章节、标签、范围或唯一锚点。
- BEFORE：完整相关原文与原逻辑链。
- WHY WRONG：数学原因，含反例及假设核验；候选注明未确认。
- 用户决策：命题/假设变化的批准内容，或尚未批准而未应用。
- AFTER：完整修后论证，含新引理的完整定理—证明。
- KEY EQUATION：关键新公式及推导。
- PROOF OBLIGATIONS ADDED：每个新条件、引理及解除位置/未解原因。
- DOWNSTREAM EFFECTS：所有受影响结果、应用点、重述、实际获准修改与重查情况。
- 实际 LaTeX 编辑：文件、准确锚点、前后内容、未写入提案。
- 编译实况：单独授权、实际命令、退出码、日志、警告、实际产物；或未运行原因。
- 反例尝试与失败路线：全部构造、预期、实际、否定原因、仍可复用部分。

### 复审

列本轮实际送审的完整原文材料及覆盖范围，随后保留 proof-review 反馈全文、问题对应关系和新问题。重大修复列 fresh 隔离实况、盲审材料全文及反馈全文；不把盲审材料与旧批评混在送审包中。

## 全局闭合与 assumption delta

- 最终命题全文与证明终点比较。
- 每项假设修前/修后、强弱关系、理由、用户决定、主定理和全部下游同步位置。
- 义务差异：原缺口、新增、实际解除、仍未解、仍假设/未验证导入。
- DAG 无环及语义循环检查、符号类型、案例覆盖、归纳、WLOG。
- 全部关键引理与修改下游反例回归结果。
- 可选重述检查发现与覆盖边界；未执行/不可用如实注明。
- 仍开放 MAJOR/MINOR 与其影响，不能被汇总结果掩盖。

## 最终边界或停止报告

- 实际完成及精确文件位置。
- 已证明 / 仍假设 / 未解决的分界及审查依据。
- 编译与数学结论分别报告。
- 已用轮数与停止原因。
- 最小阻塞 FATAL/CRITICAL 集；若只有其它阻塞亦明确列出。
- 排序挽救方案：弱化结论、加强假设、补引理、重构论证；各自损失、需求与可复用内容。
- 作者下一步需作出的具体决定。

任何续跑保留这份历史；用户重新授权轮数或范围时记录新决定，不擦除旧失败路线。
