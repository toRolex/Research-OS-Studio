# 深修复（仅用户 opt-in）

用户明确选择 `--deep-fix` 才由 repair 执行器按本节生成计划，标准问题列表与 A–H 不变。执行器将完整计划及其数学推导作为附加被审材料交给 proof-review 检查，不要求零写入的 proof-review 生成或应用补丁。适用于用户打算实际应用修复、此前最小方向过于粗略、或代数密集推导需要精确补丁的情形。以下为自然 Markdown 字段，不要求 JSON 对象。

## 每个问题的可粘贴计划

### 问题关联（issue_id）
与标准问题编号一致；保持一个问题对应一个完整计划。

### 修正命题（corrected_statement）
给出完整、paste-ready LaTeX，包含显式量词、参数 regime、全部假设、常数依赖和 uniformity scope。改变命题或假设时标“待用户决定”，可粘贴不等于已授权。

### 公式替换（changed_equations）
每个公式分别给出 BEFORE 原始 LaTeX 与 AFTER 完整替代 LaTeX；不能只写“加强估计”。

### 下游标签（downstream_labels）
列出每个需重查/重写的 `\label{...}` 键、文件、受影响的声明或证明；没有标签时用唯一锚点，说明原稿无标签。

### 最小 LaTeX 补丁计划（minimal_tex_patch_plan）
按应用顺序逐项列：

- file：精确绝对路径。
- anchor_old：文件中唯一的原始 LaTeX 片段。
- replacement_new：可直接插入的完整 LaTeX。
- 该编辑影响范围与所需用户授权。

应用前核对原文与唯一性，检查完整推导、所有新增义务、实际批准范围；不机械信任 reviewer 的编辑建议。

### 闭合测试（closure_tests）
提供 2–5 个可执行的具体检查及预期结果，例如常数依赖差异与计算一致、γ→0 还原恒等式、前后维数一致。逐项说明解析或数值方法、所需工具/资源是否已授权；工具不可用不能伪称已运行。

## 代数/类型 sanity（algebra_sanity）

当涉及 Schur test、Young、Cauchy–Schwarz、Hölder、二次型、算子范数或幂次计数，计划必须追加全部四项：

### 维数表（dimension_table）
每个符号的类型、维数与正性，例如 K(i,α) 是非负标量，‖K‖₂→₂ 是非负标量，ΣᵢVᵢ^rem 关于 w 是二次式。左右端单位、空间和矩阵相乘维度必须相容。

### 幂次计数（power_count）
列左右端每个算子范数或 Schur 因子出现的次数，展示推导并检查遗漏的平方/平方根。真正的不匹配作为数学错误交 proof-review 判定 INVALID；不能通过改写类型把错误隐藏。

### 零耦合检查（zero_coupling_check）
把 γ=0 或实际对应退化点代入，写出算式、预期恒等/消失结果及是否一致；若退化点不在原命题域内，区分边界极限与合法代入，不借非法参数制造反例。

### 常数依赖差异（constant_dependence_diff）
逐个列 BEFORE 与 AFTER 的 C 对 d,K,n 等参数的明确依赖、发生改变的原因、受影响结论与统一性范围。

## 不可用处理

计划必须足够具体以供逐项核对后编辑。“重做 Schur 步”等泛化建议不是深修复计划。某问题无法给出精确方案时，该问题写“深修复不可用”及原因，不伪造字段内容，不往标准问题列表塞入深修复专有错误类别。

拒绝给计划、追加内容截断/格式不完整、常规审查已回传但追加部分超时：保留有效常规审查，说明深修复不可用，不改变原数学问题或结论。它不单独阻塞常规人工推导；若缺的是正常证明审查则按 review 失败停止。任何恢复调用仍遵守原调用授权与轮数，不能因 opt-in 自动扩容。
