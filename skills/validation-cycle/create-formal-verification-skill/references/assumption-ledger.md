# 假设账本：外部假设、材料、版本与同步

形式检查只在它描述的对象和假设上成立。账本让下一个执行者看出：这次通过依赖了什么，哪些东西变了以后不能再引用它。

## 记录字段

| 字段 | 写什么 | 例 |
|---|---|---|
| 对象 | 被检查的代码、模型或定理 | `src/queue.rs` 的入队/出队不变量 |
| 类别 | 代码性质、形式模型、数学定理、普通测试 | 形式模型 |
| 工具与版本 | 工具名、版本或提交、标准库版本 | 求解器版本、证明助手与标准库版本 |
| 命令 | 一条可复制的运行命令 | `make verify-queue` |
| 外部假设 | 引用的外部定理、规范、生成器、公理及其来源 | 外部规范版本、生成器种子 |
| 材料 | 输入数据、规格文件、上游定义及来源版本 | 上游定义文件与其 revision |
| 覆盖 | 文件、函数、性质、界、输入域；排除项 | 覆盖两个函数与有界队列长度 ≤ 8 |
| 同步状态 | 最后确认检查仍描述当前代码的 commit、日期、命令/结果与实际输入清单 | 覆盖代码及验证资产的路径/内容摘要、已暂存/未暂存/相关未跟踪状态；commit 不能单独标识工作树 |
| 重验触发 | 哪些变化使旧结果失效 | 工具升级、外部定义改动、输入更新、覆盖代码改动 |
| 状态 | 已执行、草稿、blocked、未核实 | 草稿 |

## 规则

- **一条假设一行**，写出它支撑了哪条性质；没有对应性质的假设不记。
- **版本必须来自实际运行环境**，可以取自工具输出或锁文件；无法读取时标未核实，不按通过记录。
- **变化即失效**：工具或库版本、外部定义、输入材料、覆盖代码任一项变化后，旧通过只代表旧对象，不得替新对象背书。
- **对象可回查**：创建与维护均保存实际输入路径/摘要，包含相关未提交或被忽略输入；同 HEAD 变化仍标 stale。运行前后对账，有未审变化不推进同步记录；旧记录只有 commit 时先标未核实，再核验和执行当前对象。
- **未读即未知**：读不到的外部材料不补全、不假设其结论；相关性质保持未核实。
- **降级如实命名**：用替代手段得到的结果按实际手段标注，不借用被替代工具的结论语气。
- **草稿优先**：生成的检查若从未执行，标为草稿，不作为证据。
