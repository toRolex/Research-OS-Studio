# 候选 Idea 报告

此模板是自然语言检查单，不是统一 schema。填写实际内容；未知写明未知。用户指定格式时可调整标题，但保留材料、候选、筛选理由与评审边界。composed 只返回被分配章节。

## 材料与本轮边界

- 方向 / 问题框架 / 非目标：
- 输入材料及实际读到范围（路径、标题、章节/页码）：
- 已有结果 / 失败尝试 / 相互矛盾的证据：
- 已知资源 / 估计资源 / 未知约束：
- 本次输出授权与推理预算：
- 执行方式（并行生成者 / 单上下文顺序视角），各视角返回或缺口：

## Landscape

按方法分组；注明局限、结构性 gap、观察与推测的区别。未检索时仅就本组材料陈述覆盖范围。

## 原始候选池

每个候选一张卡；保留后来合并或暂存的卡。

### [本地编号 / 标题]

- **方法**：2–4 步，白话说明实际会做什么（仅设计，尚未执行）。
- **问题**：对象、条件、受影响者及后果。
- **两句话 pitch**：问题及后果；方法及其假设机制。
- **核心 Claim**：待检验假说/命题；明确范围、假设和机制。
- **生成自查**：Explain-It、Problem-First、Simplicity、Stakeholder、Feasibility；记录各项疑问、核心张力、抽象层级，不作质量裁决。
- **材料依据**：位置及具体观察；生成者推测单列。
- **生成视角 / 框架操作**：保留假设重述、机制映射等独特推导。
- **可选判别测试与最小可行验证**：列出三个可选检验及各自区分什么，选择其中最便宜的判别实验、对照、观测量；或证明路线、反例及必要前提。无法提出时写具体缺口。
- **结果含义**：支持条件、反证条件、负结果价值、无结论/低功效的解释。
- **资源与可行性**：数据/计算/时间及其估计依据；未知项。
- **贡献类型 / so what**：empirical / method / theory / diagnostic；任一方向的结果为何值得知道。
- **命名风险 / 最强预期异议**：生成者注释，不是独立审查结论。
- **相关工作疑问**：已读来源与待核实项；不编造查新分数。

## 非重复可行池

列出保留候选及其原始卡指针，说明实质差异（问题/机制/可区分预测）。按视角或用户指定的客观字段排列；这不是质量排名或最终 shortlist。重复不确定则保留。

## Handoff 与停止

- 给独立评审者的原始材料位置、原始候选、合并映射和未知项：
- 未覆盖视角、资料/工具缺口：
- 本次是否写文件、实际位置或未写原因：
- 下一步只建议：需要单独的查新/idea-review，以及用户采用决定。

本次仅候选生成和客观整理；未进行独立科研评审、真实验证或用户科研验收。不自动启动下一个 Workflow。
