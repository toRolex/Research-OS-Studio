# Idea Discovery Workflow

用户显式调用的研究发现入口。围绕用户目标及现有成果选用 Idea Cycle 能力；能力是可组合配方，不是必须走完的流水线。完整 Proposal 是一种目标，不是每次调用的预设终点。

## 委托继承

Gates: none

由 `/research-os` 的 `idea-discovery` 路线进入时，沿用调用者已有的目标、权限、研究额度与完成条件；独立调用时，以下输入、边界、预算与输出就是本次授权，不需先 setup。内部能力继承这份授权，不重复索要已授予的决定。

**决定门**：主要目标替换、越权、超额、未授权破坏性动作仍须停下确认；既有文件冲突先保留原件并询问。缺工具、子代理、原文或必要依赖时标记对应工作 blocked，不以串行代跑冒充独立能力。

- **用户决定**：研究目标与非目标、可用材料、权限、总预算及本次交付目标。未给出的约束保持未知，不以假设填满。
- **Agent 组织**：阅读已有材料和成果，按目标缺口选择必要能力及顺序；记录已覆盖与尚未覆盖的职责，必要时回访任一能力。不得把生成者自查算作独立评审。
- **输出**：按目标提供发现报告、候选分析或 Proposal。若用户要求完整 Discovery 报告，默认 `IDEA_DISCOVERY.md`；若目标包括 Proposal，默认 `RESEARCH_PROPOSAL.md`。既有目的文件保留并报告冲突。
- **写入范围**：只写用户已授权的目录与产物；研究材料、原始候选、文献、代码和数据只读。已授权目录内可自行选择不冲突的新文件名，并记录路径与理由。更改目标文件、覆盖既有产物或写出授权目录需另行决定。
- **资源范围**：只用宿主已有且本次授权的能力。公开检索不授权上传私有材料、付费服务、新凭据、远程写入或安装科研环境。
- **停止条件**：达到本次目标及完成条件，或遇到必须由用户决定的目标替换、越权、超额、文件冲突时，停止受影响工作并交付其余可完成部分。其他顶层 Workflow 由用户另行点名。

**完成条件**：本次目标、读到的材料、边界、预算和授权写入范围已明确或标出具体缺口；选中职责的产物已交付或说明阻塞与未完成项。

## 组合配方

先据目标和已有成果列出待解决缺口，再选择适用职责的子集；可按问题需要重排、回访或结束某项职责。全链 Discovery 只是适用时的参考配方，不是默认阶段顺序或成功条件。每次进入一项能力前读取其完整 SKILL.md 与本次要用的 reference，并满足该叶的来源、预算、评审、写入和完成要求。

| 目标缺口 | 可选能力 | 典型贡献 |
|---|---|---|
| 文献范围或来源证据不足 | `research-lit` | 有出处的 literature landscape |
| 缺少候选或需扩大视角 | `idea-generation`；卡在单一表述时可选 `creative-thinking-for-research` | 候选池、筛选理由或可检验转变 |
| 候选的新颖性未核查 | `novelty-check` | closest-work 比较或具名证据缺口 |
| 需要外部挑战 | `idea-review` | 独立 findings、证据定位与未决问题 |
| 候选需方法收敛或 Proposal | `idea-refinement` | 固定 Problem Anchor 下的路线比较与 Proposal |

已有完整材料的用户可直接从对应缺口开始；新发现的文献缺口可回访 `research-lit`，评审意见可返回 `idea-generation` 或 `idea-refinement`。不适用或已由材料满足的职责可以省略，但需将为何省略和未覆盖范围如实记录。canonical 章节和缺口标注见[组合说明](references/composition-notes.md)。

## 发现报告与停止

若本次目标包含综合报告，按[报告模板](templates/discovery-report.md)组织已完成职责的结果；独立评审实际请求与原始回复逐字完整内联到 `#独立评审` 章节并保留轮次、来源定位与未解决意见，链接或摘要不替代原文。其他叶实质结论原样合入或清楚引用其获准证据位置。Proposal 仅在用户目标需要且 `idea-refinement` 实际完成时交付。报告列出输入实际读取范围、已执行/省略/blocked 的职责、未解决问题和产物路径。交付后停止；不自动启动 pilot、实验计划、Validation 或 Writing。

**完成条件**：用户要求的产物已写入授权的新路径，或如实报告写入失败；所有职责和缺口状态可核对，且未启动额外顶层 Workflow。
