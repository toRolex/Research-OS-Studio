# 阶段边界

**阶段**是一次会话里的一块工作：确认范围、一轮证明、一轮改进、一次验收。阶段在你认为「这块做完了」时结束。

**阶段边界**只存在于两块工作之间。阶段中途继续做，或把剩余工作拆给子代理；中途压缩会丢掉正在用的推理。

## 五个选项

| 选项 | 作用 |
|---|---|
| **Continue** | 留在本会话。不切换上下文。 |
| **`/clear`** | 清空当前窗口，从空白开始。旧会话仍可恢复。 |
| **`/handoff`** | 把可携带的 Markdown 交给新的宿主、目录或同事。 |
| **Subagent** | 把范围已定、无需中途指挥的任务放进独立上下文，拿回报告。 |
| **`/compact`** | 压缩本上下文，用摘要开启同一宿主、同一目录的下一会话。 |

## 判断顺序

自上而下，第一个「是」生效。

1. **能否 Continue？** 下一阶段要把本阶段原文当 primary source，或剩余上下文装得下下一阶段。能继续就不付摘要损失。
2. **上下文对下一步是否无关？** 探索、死路和决定都可丢时用 `/clear`。清掉仍相关的上下文会失去「为什么」。
3. **是否需要换地方？** 只在换宿主、换目录或仓库、交给同事、或从阶段中途分出一个不打断当前工作的支线时用 `/handoff`。没有东西要带走就不写交接文件。
4. **任务能否离手？** 范围够紧、人不在键盘旁也能做完时用 Subagent。本会话保持不动。
5. **否则 `/compact`。** 上下文仍相关、宿主和目录不变、人还要留在环里。给下一阶段要保留的内容，例如「接下来只做 QA」。`/compact` 是默认落点，不是第一步。

除 Continue 外，其余选项都把 primary source 换成有损的 secondary source。问题按这个顺序问，是判断，不是客观开关。
