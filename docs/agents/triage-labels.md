# Triage 标签

skill 以五个标准 triage 角色来表述。本文件将这些角色映射到本仓库 issue tracker 中实际使用的 label 字符串。

| rolex/skills 中的 label | 我们 tracker 中的 label | 含义                                   |
| ----------------------- | ----------------------- | -------------------------------------- |
| `needs-triage`          | `needs-triage`          | 维护者需要评估这个 issue               |
| `needs-info`            | `needs-info`            | 等待报告者提供更多信息                 |
| `ready-for-agent`       | `ready-for-agent`       | 已完全明确，可供 AFK agent 使用        |
| `ready-for-human`       | `ready-for-human`       | 需要人工实现                           |
| `wontfix`               | `wontfix`               | 不会被处理                             |

当 skill 提到某个角色（例如“打上 AFK-ready 的 triage label”）时，使用本表格中对应的 label 字符串。

编辑右列，使其与你实际使用的词汇一致。
